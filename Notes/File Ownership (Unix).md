# Definition
> [!definition] File Ownership (Unix)[^1]
> Every Linux filesystem object records a user owner and a group owner, which determine which of the object's [[File Permissions (Unix)|permission triplets]] — owner, group, or other — applies to a given process, without themselves granting any particular permission.

# Properties
- Inspected together with the permission mode using `ls -l`.[^1]
