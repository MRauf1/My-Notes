# Definition
> [!info] Abstraction (Computer Systems)[^1]
> A major productivity technique for hardware and software design: represent a design at different levels of representation, where lower-level details are hidden to offer a simpler model at higher levels.

# Properties
- One of the [[Great Ideas in Computer Architecture]].
- Both hardware and software are constructed as hierarchical layers using abstraction, with each lower layer hiding details from the level above; see [[Abstraction Layer]] for how this layering is organized in a running system.
- The [[Instruction Set Architecture]] is the key abstract interface between hardware and low-level software: it enables many implementations of varying cost and performance to run identical software.

[^1]: [Computer Organization and Design: The Hardware/Software Interface](zotero://open-pdf/library/items/YWPB5EDC?page=34&annotation=8SHTHKRS)
