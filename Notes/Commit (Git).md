# Definition
> [!info] Commit[^1]
> A commit is the [[Git Object]] type that records a single snapshot of a project: it points to the top-level [[Tree (Git)|tree]] representing that snapshot's files, along with its parent commit(s), [[Author and Committer (Git)|author and committer]], and message.

[^1]: [Pro Git](zotero://open-pdf/library/items/Y53JUJJW?page=433&annotation=WU7H3IWE)
