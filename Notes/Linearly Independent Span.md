# Definition

> [!abstract] Theorem 1 ([[Linearly Independent]] [[Span]])[^1]
> A list of [[Vector]] $(v_1, \dots, v_n)$ in $\mathbb{F}^n$ is [[Linearly Independent]] if and only if it [[Span|spans]] $\mathbb{F}^n$.
