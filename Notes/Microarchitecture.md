# Definition
> [!info] Microarchitecture[^1]
> The organization of a processor, including its major functional units, their interconnection, and control — as distinct from its [[Instruction Set Architecture]], which specifies only the programmer-visible behavior an implementation must provide.

# Properties
- Architectural registers are the instruction set's programmer-visible registers (for MIPS, the 32 integer and 16 floating-point registers), which remain fixed by the [[Instruction Set Architecture]] even as the underlying microarchitecture (for example, whether it performs [[Dynamic Pipeline Scheduling|dynamic scheduling]] or [[Register Renaming]]) varies across implementations.
