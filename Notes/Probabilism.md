# Definition
> [!info] Probabilism[^1]
> The [[Epistemic Rationality|rationality constraint]] that an agent's [[Credence|degrees of belief]] should be [[Probability|probabilities]]. For propositions , Y$ in the agent's set of beliefs $, degrees of belief $ are probabilities if and only if they satisfy
> 1. **Nonnegativity**: (X) \geq 0$ for all  \in B$.
> 2. **Normalization**: (T) = 1$ for every [[Tautology|tautology]]  \in B$, i.e., every sentence true whatever the world is like.
> 3. **Finite additivity**: (X \lor Y) = P(X) + P(Y)$ for all , Y \in B$ such that $ and $ are incompatible.

# Properties
- Finite additivity is what gives probability theory its power: it connects degrees of belief to each other and so imposes structure on the whole set of beliefs.
- These three rules are the finitely additive version of the Kolmogorov axioms of [[Probability]]; the standard mathematical axiomatization instead requires countable additivity, \left(\bigvee_{i=1}^{\infty} X_i\right) = \sum_{i=1}^{\infty} P(X_i)$ for pairwise incompatible $, as in a [[Probability Space|probability space]]. Whether rationality requires countable additivity is itself debated (de Finetti rejected it).
- Normalization is challenged by the [[Logical Omniscience Objection]].
- Supported by three main arguments:
	- [[Dutch Book Argument]] (pragmatic), and its [[Depragmatized Dutch Book Argument|depragmatized]] variant.
	- [[Accuracy Argument]] (purely epistemic).
	- [[Representation Theorem Argument]] (from preferences).
- A very weak constraint on rationality: it only constrains how degrees of belief fit together, not which particular values they should take, so wildly different credences can all be probabilistic.
