# Definition

> [!abstract] Theorem 1 ([[Rank]] [[Domain]] [[Codomain]])[^1]
> If $T \in \mathcal{L}(V, W)$, then $rank(T) \leq min(dim(V), dim(W))$.

> [!abstract] Theorem 2 ([[Matrix]] Version)
> If $A \in M_{m, n}(\mathbb{F})$, then $rank(A) \leq min(m, n)$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=193)
