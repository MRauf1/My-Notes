# Definition

> [!abstract] Theorem 1 ([[Continuous Random Variable]] [[Probability]] [[Inequality]] Theorem)[^1]
> $$
> \begin{align}
> P(a < X < b) = P(a \leq X < b) = P(a < X \leq b) = P(a \leq X \leq b)
> \end{align}
> $$

[^1]: [Introduction to Mathematical Statistics](zotero://open-pdf/library/items/P3TUBR4A?page=66)
