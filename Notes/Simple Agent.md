# Definition
> [!info] Simple Agent[^1]
> An agent whose [[Utility Function|utility]] is proportional to their money, i.e., who cares only about money, so that monetary payoffs function as utilities.

# Properties
- Restricting to simple agents guarantees that betting prices match degrees of belief, securing premise P1 of the [[Dutch Book Argument]] and premise P1' of the [[Depragmatized Dutch Book Argument]].

[^1]: [A Critical Introduction to Formal Epistemology](zotero://open-pdf/library/items/9XYCZDPF?page=42)
