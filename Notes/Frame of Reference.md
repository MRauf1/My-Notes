# Definition
> [!info] Frame of Reference[^1]
> A frame of reference (or coordinate system) is the reference relative to which measurements of distance and time are made. Such measurements depend on the observer: two observers moving relative to each other will not in general measure the same distances and time intervals for what appear to be the same events.

# Properties
- Distances and time intervals take different magnitudes depending on the frame of reference used to measure them.

[^1]: [The Feynman Lectures on Physics, Vol. I, Ch. 5: Time and Distance](https://www.feynmanlectures.caltech.edu/I_05.html)
