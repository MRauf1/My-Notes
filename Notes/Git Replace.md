# Definition
> [!info] Git Replace[^1]
> Git's replace mechanism lets one object be substituted for another wherever [[Git]] looks it up, without altering the original object's hash or rebuilding the history around it.

# Properties
- This is commonly used to swap in a corrected version of a commit in place of an old one, without needing to rewrite every descendant commit the way a full history rewrite would require.
