# Definition

Imperative that is a means to achieve a goal/fulfill a desire.[^1] It is not a [[Moral Imperative]] as such action is neither praise or blame-worthy.

As [[Immanuel Kant]] put it, the imperative "says only that the action is good for some actual or possible purpose." Unlike a [[Categorical Imperative]], which commands unconditionally regardless of one's desires, a hypothetical imperative only binds conditionally on holding the goal/desire in question.

[^1]: [Introduction to Philosophy](zotero://open-pdf/library/items/M84L5RRJ?page=288)
