# Definition
> [!info] Depragmatized Dutch Book Argument (Christensen, 2001)[^1]
> A variant of the [[Dutch Book Argument]] for [[Probabilism]] that focuses on beliefs rather than monetary loss. Restricted to [[Simple Agent|simple agents]], it states:
> - **P1'.** A simple agent sanctions as fair betting prices matching their [[Credence|degrees of belief]].
> - **[[Dutch Book Theorem]].** If a set of betting prices violates the rules of probability, then there is a set of bets which will inflict on the agent a sure loss.
> - **P2'.** If a simple agent sanctions as fair a set of bets that inflict a sure loss, then the agent's degrees of belief are irrational.
> - **C'.** If a simple agent's degrees of belief violate the rules of probability, then they are irrational.

An agent's degree of belief in a proposition **sanctions as fair** a possible bet if and only if it provides justification for evaluating that bet as fair, i.e., for being indifferent to taking either side of the bet. This is an informal, intuitive normative connection between the agent's beliefs and their preferences over possible bets.

# Properties
- Avoids the objections to the original [[Dutch Book Argument]], since the agent need never actually bet or lose money.
- Objection: it is not purely epistemic, since what an agent sanctions as fair depends on their preferences as well as the prices.
- On this reading, the point of a Dutch Book is not that the agent will lose money but that it reveals an inconsistency within the agent's beliefs, which is obviously irrational.
