# Definition
> [!definition] Web Application Framework[^1]
> A web application framework is a set of modular building blocks offering facilities for common web infrastructure and features, such as templates, multiple users, and database support, that a [[Web Server|web server]] runs on top of.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=371&annotation=A375BF7Y)
