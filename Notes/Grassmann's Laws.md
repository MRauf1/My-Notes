# Definition
> [!info] Definition (Grassmann's Laws)[^1]
> Empirical laws governing color matching: if color $A$ matches a given combination of primary colors, and color $B$ matches that same combination, then $A$ matches $B$ (transitivity). More generally, color matches combine linearly, so the amounts of the primaries needed to match a color behave as linear-combination coefficients.

# Properties
- Justifies treating the amount of each primary required to match a color as a set of coordinates, the [[Tristimulus Values]], indicating that color.
- Follows from the [[Trichromatic Theory of Color Vision|linearity of the eye's photoreceptor responses]] to incoming light.

[^1]: [MIT Vision Book - Color](https://visionbook.mit.edu/color.html)
