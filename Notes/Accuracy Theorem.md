# Definition
> [!info] Accuracy Theorem[^1]
> If a set of beliefs violates the rules of [[Probabilism|probability]], then it is [[Accuracy Dominance|accuracy dominated]] by one that doesn't, i.e., for any nonprobabilistic beliefs there is a set of probabilistic beliefs that dominates it.

# Properties
- Its converse is the [[Converse Accuracy Theorem]].
- The accuracy analogue of the [[Dutch Book Theorem]] and the mathematical core of the [[Accuracy Argument]].
- Geometrically, for the Brier score, the probabilistic credence functions form a convex set (the convex hull of the truth-value vectors of the possible worlds), and projecting a nonprobabilistic credence function onto this set yields one that is closer to every world's truth-value vector.

[^1]: [A Critical Introduction to Formal Epistemology](zotero://open-pdf/library/items/9XYCZDPF?page=47)
