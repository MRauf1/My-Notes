# Definition
> [!definition] State (Computing)[^1]
> A state is a particular arrangement of the bits in memory.

# Properties
- Composed of [[Bit|bits]] in [[Main Memory]].
- A [[Process (Computing)|process]] is, in essence, a state (or image) residing in memory.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=27&annotation=NBSDE75L)
