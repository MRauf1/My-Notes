# Definition
> [!definition] Vim[^1]
> Vim is a modal text editor: the same key can carry different meanings depending on the editor's current mode.

# Types
- Normal mode — interprets keys as navigation and editing commands.
- Insert mode — inserts typed text.
- Command-line mode — accepts commands such as writing or quitting.

# Properties
- Pressing `Esc` returns to Normal mode from any other mode.[^1]
- Editing commands follow the [[Vim Editing Grammar]], combining an operator with a motion or text object.

[^1]: [Linux Journey: Advanced Text-Fu](https://labex.io/linuxjourney/courses/advanced-text-fu)
