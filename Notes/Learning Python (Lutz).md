# Review[^1]

A very extensive and dense book on Python. It explains everything well and in-depth, but it seems to be more aimed towards beginners. For others with already some experience in Python, at most, one should just skim through some of the relevant sections instead of going end-to-end through this book. A book such as this is also always at risk of getting outdated, so it might be better to just keep up with Python's evolving documentation instead.

[^1]: [Learning Python](zotero://open-pdf/library/items/C6PDA59I?page=1)
