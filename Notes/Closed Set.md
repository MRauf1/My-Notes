# Definition

> [!info] Definition 1 (Closed [[Set]])
> [[Set]] containing all [[Limit of Sequence]] of [[Sequence]] consisting of the set's elements.

> [!info] Definition 2 (Closed Set in Terms of [[Metric Space]])[^1]
> Let $(S, d)$ be a [[Metric Space]]. [[Subset]] $E \subseteq S$ is a closed set if its [[Set Complement]] $S \setminus E$ is an [[Open Set]].
> $E$ is closed if $E = S \setminus U$ where $U$ is an [[Open Set]].

> [!info] Definition 3 (Closed Set via Limit Points)[^2]
> Let $(S, d)$ be a [[Metric Space]] and $E \subseteq S$. $E$ is closed if every [[Limit Point]] of $E$ is a point of $E$.

This is equivalent to the complement-based Definition 2, and is the more fundamental definition in general [[Metric Space|metric spaces]] (it does not require first defining open sets or sequences).

[[Interval Notation|Closed interval]] $[a, b]$ is a closed set because it contains all of the boundary points.
