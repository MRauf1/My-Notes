# Definition
> [!definition] Identification (Computer Security)[^1]
> Identification is the part of user security that answers the question of who a user is.

# Properties
- Distinct from [[Authentication (Computer Security)|authentication]], which asks a user to prove that identity, and [[Authorization (Computer Security)|authorization]], which limits what an identified user is allowed to do.[^1]
- On a Linux system, the kernel identifies only numeric user IDs for process and file ownership; it knows nothing of the usernames, passwords, or other identity information layered on top in [[User Space|user space]].[^2]
