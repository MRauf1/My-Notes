# Definition
> [!info] GPG Signing[^1]
> [[Git]] can cryptographically sign commits and [[Git Tag|tags]] using GPG, letting others verify that a given piece of history genuinely originated from a specific, trusted person.

# Properties
- Verifying a signature requires the signer's public key to already be present in the verifier's own keyring.
