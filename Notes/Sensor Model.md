# Definition
> [!info] Sensor Model[^1]
> Knowledge, encoded in an agent program, about how the state of the world is reflected in the agent's percepts.

# Properties
- Used together with a [[Transition Model|transition model]] by a [[Model-Based Reflex Agent|model-based agent]] to keep track of the state of the world.

[^1]: [Russell and Norvig, 2022, p. 70](zotero://open-pdf/library/items/JZXT5DZQ?page=70&annotation=CIAJ7HAB)
