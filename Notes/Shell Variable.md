# Definition
> [!definition] Shell Variable[^1]
> A shell variable is a temporary variable, specific to the [[Shell (Unix)|shell]], that stores the value of a text string.

# Properties
- Useful for keeping track of values in scripts.
- Some shell variables control the way the shell behaves.
- Unlike [[Environment Variable|environment variables]], shell variables cannot be accessed in the commands that the shell runs.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=46&annotation=S79JE7GE)
