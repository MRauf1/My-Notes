# Definition
> [!info] Block Device[^1]
> A block device is a [[Device File]] that exposes data in fixed-size chunks (blocks) rather than as a stream, so that processes have random access to any block with the kernel's help.

# Properties
- Has a fixed, easily indexed total size, unlike a [[Character Device]].
- [[Disk|Disks]] are the archetypal block device, since they can readily be split into blocks of data.
