# Definition

- $(R^{-1})^{-1} = R$
- $Domain(R^{-1}) = Range(R)$
- $Range(R^{-1}) = Domain(R)$
- $T \circ (S \circ R) = (T \circ S) \circ R$
- $(S \circ R)^{-1} = S^{-1} \circ R^{-1}$
