# Definition
> [!definition] Cloud Computing[^1]
> Cloud computing is a catch-all term for sophisticated tools, built on top of [[Virtual Machine|virtual machine]] technology, that ease resource management by letting users provision and control computing resources remotely.

- [[Platform as a Service (PaaS)]]
