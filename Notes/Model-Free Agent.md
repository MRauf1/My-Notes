# Definition
> [!info] Model-Free Agent[^1]
> A [[Utility-Based Agent|utility-based agent]] that can learn what action is best in a particular situation without ever learning exactly how that action changes the environment, i.e. without a [[Transition Model|transition model]].

[^1]: [Russell and Norvig, 2022, p. 74](zotero://open-pdf/library/items/JZXT5DZQ?page=74&annotation=DKYGSJQR)
