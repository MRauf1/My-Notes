# Definition
> [!definition] Shell Script[^1]
> A shell script is a text file that contains a sequence of shell commands.

# Properties
- Executed by a [[Shell (Unix)|shell]].
- Many important parts of a Unix system are implemented as shell scripts.
- Best kept short, since shell scripts excel at manipulating simple files and commands; reaching for a built-in like `read` to do complicated string or arithmetic operations is a sign to switch to a scripting language such as Python, Perl, or awk instead.[^2]
