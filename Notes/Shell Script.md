# Definition
> [!definition] Shell Script[^1]
> A shell script is a text file that contains a sequence of shell commands.

# Properties
- Executed by a [[Shell (Unix)|shell]].
- Many important parts of a Unix system are implemented as shell scripts.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=37&annotation=3XTGVMKD)
