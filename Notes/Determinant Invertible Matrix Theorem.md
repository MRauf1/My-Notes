# Definition
> [!abstract] Theorem 1 (Corollary 6.6)[^1]
> A matrix $A \in M_n(\mathbb{F})$ is [[Invertible Linear Map|invertible]] if and only if $\det(A) \neq 0$. In that case,
> $$
> \det(A^{-1}) = (\det A)^{-1}
> $$
