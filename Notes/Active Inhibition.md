# Definition
> [!info] Active Inhibition[^1]
> The view that forgetting is not the loss of a memory but a mental barrier erected between the conscious mind and long-term memory (MacLeod, 2007). It filters out irrelevant memories so we aren't flooded and can focus on our surroundings.

# Properties
- Paradoxically, forgetting facilitates long-term learning.[^1]
- **Shereshevsky** (Luria's patient) could remember almost anything but could hardly forget. Important things got lost among irrelevant details, and he struggled to grasp the gist, the concepts behind particulars, or which facts mattered. He lacked the ability to forget systematically.[^2]
- **Context-dependent memory.** Recall is easier in the same context as learning, e.g., being tested in the same room with the same background noise (Bjork, 2011).[^3]
- Implication: let the brain forget details and delegate storage to an external system ([[Zettelkasten]]) while you focus on understanding.
