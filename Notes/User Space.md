# Definition
> [!definition] User Space[^1]
> User space (informally, userland) is the portion of main memory that user processes can access. Because a process is simply a state in memory, user space also refers collectively to the memory of all running processes.

# Properties
- Forms the upper [[Abstraction Layer|level]] of a Linux system, above the [[Kernel (Operating System)|kernel]].
- Corresponds to execution in [[User Mode]].
- Contrasts with [[Kernel Space]].
- Composed of the memory images of all running [[Process (Computing)|processes]].

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=27&annotation=NBSDE75L)
