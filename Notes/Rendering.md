# Definition
> [!info] Definition (Rendering)[^1]
> Rendering is a process that takes as its input a set of objects and produces as its output an array of pixels, one way or another considering how each object contributes to each pixel.

# Properties
- Assumes the output is a [[Raster Image]] (as opposed to a [[Vector Image]]) with pixels arranged per the [[Raster Image Coordinate Convention]].
- Organized in two general ways: [[Object-Order Rendering]] and [[Image-Order Rendering]].
- [[Ray Tracing]] is the canonical image-order rendering algorithm.

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=84&annotation=4U5WR7CJ)
