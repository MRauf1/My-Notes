# Definition
> [!definition] tee (Command)[^1]
> `tee` is the command that copies part of a [[Pipeline (Unix)|pipeline]]'s data flow to a file while continuing to send that data onward to the next command.

[^1]: [Linux Journey: Text-Fu](https://labex.io/linuxjourney/courses/text-fu)
