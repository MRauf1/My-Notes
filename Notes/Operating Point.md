# Definition
> [!info] Definition (Operating Point)[^1]
> A particular point—a setting of the parameters $\theta$—at which a [[Cost Function]] is currently being evaluated during an iterative optimization process.

# Properties
- Each step of [[Gradient Descent]] and related [[Gradient-Based Learning|gradient-based learning algorithms]] computes a locally loss-minimizing direction at the current operating point, then moves to a new operating point with lower cost.

[^1]: [MIT Vision Book - Gradient Descent](https://visionbook.mit.edu/gradient_descent.html)
