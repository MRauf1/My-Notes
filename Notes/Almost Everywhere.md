# Definition
> [!info] Almost Everywhere[^1]
> Let $(X, \mathcal{M}, \mu)$ be a [[Measure Space]]. A statement about points $x \in X$ holds **almost everywhere** (a.e.), or for **almost every** $x$, if it is true except for $x$ in some [[Null Set (Measure Theory)|null set]]. For precision one says $\mu$-almost everywhere.

# Properties
- Countably many a.e. statements hold simultaneously a.e., since a countable union of null sets is null.
- Whether the exceptional set itself must be measurable is a technicality removed by working with a [[Complete Measure]].
- In probability, "almost surely" is almost everywhere with respect to a probability measure ([[Probability Space]]).
