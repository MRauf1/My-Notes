# Definition

> [!info] Definition 1 (Precision)[^1]
> Precision refers to the number of digits with which a number is expressed, as opposed to [[Accuracy]], which refers to the number of correct [[Significant Digits]] in approximating some desired quantity.

# Properties
- In a [[Floating-Point Number System]], precision corresponds to the number of base-$\beta$ digits $p$ retained in the mantissa.
