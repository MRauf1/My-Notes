# Definition

> [!info] Definition 1 (Partial [[Order]])[^1]
> [[Relation]] $R: A \rightarrow A$ is a partial order if it is [[Reflexive Relation]], [[Transitive Relation]], and [[Antisymmetric Relation]].

Unlike [[Total Order]], not every two elements can be compared with each other.
