# Definition
> [!info] Oriented Simplicial Complex[^1]
> An (abstract) oriented simplicial complex is an [[Abstract Simplicial Complex]] in which each simplex is assigned one of its two orientations (an [[Oriented Simplex]]). There are no constraints: orientations may be assigned arbitrarily.

# Properties
- When possible, it is convenient to choose orientations so that $k$-simplices sharing a $(k-1)$-face have the same relative orientation (e.g., all triangles of a planar triangulation clockwise); for surfaces this is a consistent orientation of an oriented [[Simplicial Surface]].[^1]
- Admits [[Simplicial Adjacency Matrix|signed adjacency matrices]] that record relative orientation as well as connectivity.
