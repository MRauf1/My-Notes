# Definition
> [!definition] Database (Computing)[^1]
> A database is a specialized service for storing and retrieving data, attractive for offering easy, uniform ways to manage individual pieces and groups of data alongside superior access performance.

# Types
- [[Relational Database]]
- [[Non-Relational Database]]

# Properties
- Fundamentally, calling data a database means it is self-describing and has a schema; for very large scientific datasets, it is often more efficient to move queries to the data than the data to the user ([[Gray's Laws]], [[Laboratory Information Management System]]).[^3]
- Owes its superior retrieval performance chiefly to indexing, which keeps track of where data is located.[^2]
