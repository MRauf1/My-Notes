# Definition

> [!abstract] Theorem 1 ([[Linear Map]] [[Injective Function]] [[Kernel]])[^1]
> A [[Linear Map]] is [[Injective Function]] if and only if $ker(T) = \{0\}$.
> A [[Linear Map]] $T: \mathbb{F}^n \rightarrow \mathbb{F}^m$ is [[Injective Function]] if and only if the columns of its [[Matrix]] are [[Linearly Independent]].

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=140)
