# Definition

Cone is a solid figure with a [[Circle|circular]] base with radius $r$ and a vertex. The height $h$ is the [[Distance|distance]] between the base and the vertex.[^1]

![[Cone.png]]

# Properties

## [[Surface Area|Surface Area]]

$$S = \pi r^2 + \pi r l, \quad l = \sqrt{r^2 + h^2} \text{ (slant height)}$$

## [[Volume|Volume]]

$$V = \frac{1}{3} \pi r^2 h$$

The $1/3$ factor comes from integrating the cross-sectional area over the height: each circular cross-section at height $x$ from the vertex has radius $\frac{x}{h} r$, so $V = \int_0^h \pi \left(\frac{x}{h} r\right)^2 dx = \frac{1}{3} \pi r^2 h$, exactly a third of the cylinder of the same base and height.
