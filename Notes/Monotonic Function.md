# Definition

> [!info] Definition 1 (Monotonic [[Function]])
> [[Function]] that is either [[Increasing Function]] or [[Decreasing Function]].

> [!info] Definition 2 (Monotonically Increasing/Decreasing)[^1]
> Let $f$ be real on $(a, b)$. Then $f$ is monotonically increasing on $(a, b)$ if $a < x < y < b$ implies $f(x) \leq f(y)$. If the last inequality is reversed, $f$ is monotonically decreasing. The class of monotonic functions consists of both the increasing and the decreasing functions.

In Definition 2, "increasing" is non-strict, i.e. [[Non-Decreasing Function|non-decreasing]].

# Properties
- [[Monotonic Function One-Sided Limit Theorem]]: one-sided limits exist everywhere; no [[Discontinuity of the Second Kind|discontinuities of the second kind]].
- [[Monotonic Function Discontinuity Countable Theorem]]
- Every continuous [[Open Map]] of $\mathbb{R}$ into $\mathbb{R}$ is monotonic.
