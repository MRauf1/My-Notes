# Definition
> [!info] Statement (Python)[^1]
> The code written to tell Python what a program should do; Python is a procedural, statement-based language, so combining statements specifies the procedure Python performs to satisfy a program's goals.

# Properties
- If a program can be described as doing things with stuff, statements are the "doing," while [[Object (Python)|objects]] are the "stuff" being acted on.
- A [[Compound Statement (Python)|compound statement]] nests other statements inside it; a simple statement, such as an [[Assignment Statement (Python)|assignment]] or a function call, does not.
