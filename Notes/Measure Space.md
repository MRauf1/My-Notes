# Definition
> [!info] Measure Space[^1]
> If $(X, \mathcal{M})$ is a [[Measurable Space]] and $\mu$ is a [[Measure (Measure Theory)|measure]] on $(X, \mathcal{M})$, the triple $(X, \mathcal{M}, \mu)$ is a measure space.

# Types
- Classified by the size of $\mu$: [[Finite Measure|finite]], [[Sigma-Finite Measure|$\sigma$-finite]], [[Semifinite Measure|semifinite]].
- A [[Probability Space]] is a measure space with $\mu(X) = 1$.

# Properties
- [[Measure Basic Properties]]
- Can always be enlarged to a [[Complete Measure|complete]] measure space ([[Measure Completion Theorem]]).
