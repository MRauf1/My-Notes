# Definition

> [!abstract] Theorem 1 ([[Matrix Inverse]] Algorithm)[^1]
> Form the [[Augmented Matrix]] $[A | I_n]$ and put it into [[Reduced Row Echelon Form]]. If the end result is of the form $[I_n | B]$, then $A$ is [[Invertible Linear Map]] and its [[Matrix Inverse]] is $B$. Otherwise, $A$ is singular.
> In other words, a [[Matrix]] $A$ is [[Invertible Linear Map]] if and only if its [[Reduced Row Echelon Form]] is $I_n$.
