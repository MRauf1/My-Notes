# Definition

> [!info] Definition 1 (Minimal Element)[^1]
> Let $R$ be a [[Partial Order]], $B \subseteq A$, $b \in B$. Then $b$ is the minimal element of $B$ if there does not exist $x \in B$, $xRb \land x \neq b$.

Minimal element is an element that is not smaller than any other element. There can be multiple minimal elements in a [[Partial Order]].

The reverse of this is the [[Relation Maximal Element]].

In [[Total Order]], [[Relation Smallest Element]] and [[Relation Minimal Element]] are the same.

[^1]: [HOW TO PROVE IT: A Structured Approach, Second Edition](zotero://open-pdf/library/items/THI2Q4PN?page=206)
