# Definition

> [!abstract] Theorem 1 ([[Kernel]] [[Linear System of Equations]])[^1]
> Suppose that the [[Linear System of Equations]] $Ax = b$ is consistent. The system has a unique solution if and only if $ker(A) = \{0\}$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=140)
