# Definition

> [!abstract] Theorem 1 ([[Upper Triangular Matrix]] [[Lower Triangular Matrix]] [[Invertible Linear Map]])[^1]
> [[Upper Triangular Matrix]] is [[Invertible Linear Map]] if and only if all of its diagonal entries are non-zero.
> [[Lower Triangular Matrix]] is [[Invertible Linear Map]] if and only if all of its diagonal entries are non-zero.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=235)
