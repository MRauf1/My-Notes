# Definition
> [!definition] Compositing Window Manager[^1]
> A compositing window manager is a lightweight [[Window Manager|window manager]] that only arranges windows and does minimal management of display memory, letting applications instead render their windows' contents directly into display memory.

# Properties
- Emerged because having a server manage clients, their windows, and act as an intermediary for window memory — as the [[X Window System]] does — became a performance burden.[^1]
- The architectural idea behind [[Wayland]].

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=330&annotation=SP7KAYNY)
