# Definition
> [!info] Certainty Theory of Acceptance[^1]
> Agent $A$ rationally [[Acceptance|accepts]] $H$ if and only if $A$'s [[Credence|degree of belief]] in $H$ is $1$. The version of the [[Threshold Theory of Acceptance]] with threshold $t = 1$.

# Properties
- Avoids the [[Lottery Paradox]]: since accepted hypotheses all have credence $1$, their conjunction also has credence $1$, so there is no mismatch between individual and conjoint credence, unlike under [[Acceptance Closure]] with a threshold below $1$.
- Assigns the same degree of belief, $1$, to everything accepted, even though accepted hypotheses can plausibly differ in how strongly they are believed.
- Since an agent can be wrong about, and is rarely completely certain of, any given hypothesis, this theory implies there is almost nothing an agent should accept, threatening the usefulness of the concept of [[Acceptance]] itself.

[^1]: [A Critical Introduction to Formal Epistemology](zotero://open-pdf/library/items/9XYCZDPF?page=28)
