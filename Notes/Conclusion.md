# Definition

What we are trying to [[Proof|prove]] through the [[Premise|premises]].[^1] In a valid [[Argument|argument]], the conclusion is forced by the premises: it is true whenever all the premises are true.

# Properties
- Contrapositively, if the conclusion of a valid argument is false, then at least one premise is false ([[Modus Tollens]]).
- The converse fails: a false premise says nothing about the conclusion, which may be true or false. For example, "$P \land Q$, therefore $Q$" is valid, and with $P$ false and $Q$ true it has a false premise and a true conclusion.

[^1]: [HOW TO PROVE IT: A Structured Approach, Second Edition](zotero://open-pdf/library/items/THI2Q4PN?page=22)
