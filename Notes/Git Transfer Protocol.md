# Definition
> [!info] Git Transfer Protocol[^1]
> A Git transfer protocol is one of several distinct mechanisms [[Git]] can use to move repository data between a local clone and a [[Remote Repository (Git)|remote repository]], each with its own trade-offs in performance, security, and ease of setup.
