# Definition

In [[Statistical Learning]], given input $X$ and true output $Y$, we assume there is a relationship between the two written in general as $Y = f(X) + \epsilon$ where $f$ is some fixed but unknown [[Function]] of $X$ and $\epsilon$ is the random error term, which is [[Independent Random Variable]] of $X$ and has a [[Mean]] of $0$. Normality of $\epsilon$ is not required by this general formulation; it is only an additional assumption needed for specific inference procedures (e.g. exact hypothesis tests and confidence intervals).[^1]
