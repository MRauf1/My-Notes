# Definition

> [!abstract] Theorem 1 ([[Kernel]] [[Vector Subspace]])[^1]
> Let $T \in \mathcal{L}(V, W)$. Then $ker(T)$ is a [[Vector Subspace]] of $V$.

# Properties
- Application: error detection with a [[Parity-Check Matrix]] ($\ker B = $ the code).
