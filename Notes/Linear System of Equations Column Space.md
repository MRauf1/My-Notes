# Definition

> [!abstract] Theorem 1 ([[Linear System of Equations]] [[Matrix Column Space]])[^1]
> Let $A \in M_{m, n}(\mathbb{F})$. The [[Linear System of Equations]] $Ax = b$ is consistent if and only if $b$ is in the [[Matrix Column Space]] of $A$.

In a linear system, we are essentially checking if $b$ is a [[Linear Combination]] of the columns of $A$ where the coefficients/scalars are just the entries of $x$.
