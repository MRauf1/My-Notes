# Definition
> [!info] Five Classic Components of a Computer[^1]
> Every computer is organized into five classic components: input, output, memory, datapath, and control, with the latter two sometimes combined and called the processor (or [[Central Processing Unit]]).

# Types
- Input device — a mechanism through which the computer is fed information, such as a keyboard.
- Output device — a mechanism that conveys the result of a computation to a user or another computer, such as a display.
- Memory — the storage area holding programs and the data they need while running; see [[Memory Hierarchy]].
- Datapath — the component of the processor that performs arithmetic operations.
- Control — the component of the processor that commands the datapath, memory, and I/O devices according to the instructions of the program.

# Properties
- The processor gets instructions and data from memory; input writes data to memory and output reads data from memory; control sends the signals that determine the operations of the datapath, memory, input, and output.
