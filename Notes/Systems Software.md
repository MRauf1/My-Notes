# Definition
> [!info] Systems Software[^1]
> Software that provides services that are commonly useful, including operating systems, compilers, loaders, and assemblers.

# Types
- [[Operating System]] — interfaces between a user's program and the hardware, providing supervisory functions.
- [[Compiler]] — translates a high-level language program into assembly language.
- [[Assembler]] — translates assembly language into machine language.
- [[Linker]] — combines object files and resolves labels into an executable file.
- [[Loader]] — places an object program into main memory ready for execution.
