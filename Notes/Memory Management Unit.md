# Definition
> [!definition] Memory Management Unit[^1]
> The memory management unit (MMU) is CPU hardware that enables [[Virtual Memory]] by intercepting a process's memory accesses and translating them into physical memory locations.

# Properties
- Performs its translation using a [[Page Table|memory address map]] maintained by the [[Kernel (Operating System)|kernel]].
