# Definition
> [!definition] Network File System (NFS)[^1]
> NFS is the standard system Unix machines use to share files with each other over a network.

# Properties
- Can be served over both [[Transmission Control Protocol (TCP)|TCP]] and [[User Datagram Protocol (UDP)|UDP]].[^1]
- Exists in many different versions suited to different scenarios, with a wide range of authentication and encryption techniques.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=310&annotation=MAUHC7MC)
