# Definition
> [!info] Multigraph[^1]
> A [[Graph]] in which there can be multiple [[Edge|edges]] between the same pair of nodes; in a typed multigraph, these parallel edges may have different types.

# Properties
- Generalizes the [[Simple Graph]], which forbids parallel edges and self-loops.[^2]
- Its structure cannot be captured by a single binary [[Adjacency Matrix|adjacency matrix]]; one uses entries counting edges, or one adjacency matrix per edge type.[^2]
- A [[Knowledge Graph]] is a directed heterogeneous multigraph.[^1]
