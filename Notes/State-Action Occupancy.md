# Definition
> [!info] State-Action Occupancy
> The analogue of [[Discounted State Occupancy]] defined over state-action pairs rather than states alone, for a [[Markov Decision Process]] and [[Policy]] $\pi$.

# Properties
- The notation $d^\pi$ is often used to refer to either the state or the state-action occupancy, when it is clear from context which is meant.
- The feasible region of the [[Dual Linear Program (Markov Decision Process)|dual linear program]] for planning is exactly the set of discounted state-action occupancies of stationary policies, characterized by the [[Bellman Flow Equations]].
