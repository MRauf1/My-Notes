# Definition

The IEEE floating-point standard reserves two special values for exceptional situations, both implemented through special reserved values of the exponent field.[^1]

# Types
- **Inf** (infinity): the result of dividing a finite number by zero, such as $1/0$.
- **NaN** (not a number): the result of an undefined or indeterminate operation, such as $0/0$, $0 \times \text{Inf}$, or $\text{Inf}/\text{Inf}$.
