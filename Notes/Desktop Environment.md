# Definition
> [!definition] Desktop Environment[^1]
> A desktop environment is a larger package bundling a [[Graphical Toolkit|graphical toolkit]] and other libraries together, so that applications can cooperate on details a toolkit alone cannot provide, such as sharing data with one another or updating a shared notification bar.

# Properties
- Also includes numerous support files, such as icons and configurations, that make up themes, bound together with documents describing design conventions — how application menus and titles should appear, and how applications should react to certain system events.[^2]
