# Definition
> [!info] Logical Omniscience Objection[^1]
> The objection that the normalization rule of [[Probabilism]], and therefore probabilism itself, should be rejected because it entails that rational agents should have [[Credence|credence]] $ in all [[Tautology|tautologies]], including all mathematical and logical truths, not just the known ones.

# Properties
- Arises because known and unknown tautologies come apart: every mathematical truth (e.g., a theorem whose proof the agent has never heard of) is true in all possibilities, so normalization demands certainty in it regardless of the agent's evidence.

[^1]: [A Critical Introduction to Formal Epistemology](zotero://open-pdf/library/items/9XYCZDPF?page=37)
