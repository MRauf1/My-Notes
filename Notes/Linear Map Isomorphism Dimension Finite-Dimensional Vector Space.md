# Definition

> [!abstract] Theorem 1 ([[Linear Map Isomorphism]] [[Dimension]] [[Finite-Dimensional Vector Space]])[^1]
> Let $V, W$ be [[Finite-Dimensional Vector Space]]. Then $dim(V) = dim(W)$ if and only if there is a [[Linear Map Isomorphism]] between $V$ and $W$.

> [!abstract] Theorem 2 (Corollary)
> If $dim(V) = n$, then there is a [[Linear Map Isomorphism]] between $V$ and $\mathbb{F}^n$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=185)
