# Definition
> [!info] None (Python)[^1]
> A special placeholder [[Object (Python)|object]] and the sole value of its own data type, commonly used to initialize names and to signal the absence of a result.

# Properties
- Always evaluates as false in logical tests, much like a null pointer in C serves as an empty placeholder[^2].
