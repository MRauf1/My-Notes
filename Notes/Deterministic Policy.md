# Definition
> [!info] Deterministic (and Stationary) Policy
> A [[Policy]] $\pi: \mathcal{S} \to \mathcal{A}$ that maps each state to a single action, $a_t = \pi(s_t)$.

# Properties
- A special case of a [[Stochastic Policy]] in which $\pi(s)$ is a point mass for every $s \in \mathcal{S}$.
