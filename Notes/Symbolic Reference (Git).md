# Definition
> [!info] Symbolic Reference[^1]
> A symbolic reference is a [[Reference (Git)|reference]] that, instead of directly containing a commit's hash the way an ordinary reference does, contains a pointer to another reference.

# Properties
- [[HEAD (Git)|HEAD]] is ordinarily a symbolic reference to whichever branch is currently checked out, which is how Git knows which branch reference to update when a new commit is created.
