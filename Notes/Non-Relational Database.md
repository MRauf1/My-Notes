# Definition
> [!definition] Non-Relational Database[^1]
> A non-relational database (NoSQL database) is a [[Database (Computing)|database]] built to solve particular problems that a [[Relational Database|relational database]] does not easily handle, such as storing and indexing entire documents, or maximizing performance for simple key-value access.

# Properties
- Has no common query language analogous to SQL; instead, each is accessed through its own variety of interfaces and commands.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=372&annotation=MQKY3UDE)
