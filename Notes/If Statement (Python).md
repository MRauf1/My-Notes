# Definition
> [!info] If Statement (Python)[^1]
> A [[Compound Statement (Python)|compound statement]] consisting of an `if` test, zero or more optional `elif` ("else if") tests, and a final optional `else` block; Python runs the block associated with the first test that evaluates true, or the `else` block if every test is false.

# Properties
- Multiple-choice logic that picks among several fixed values can often be coded more flexibly at runtime by indexing a [[Python Dictionary|dictionary]] built dynamically (a key acting as a "switch") instead of a long `if`/`elif` chain[^2].
- As of Python 3.10, the [[Match Statement (Python)|match statement]] offers dedicated syntax for this same kind of multiple-choice branching.
