# Definition
> [!info] Centralized Workflow[^1]
> A centralized workflow is a [[Git Collaboration Workflow]] in which a single central repository accepts all contributed code and every developer synchronizes their work directly with it, mirroring how a [[Centralized Version Control System]] operates.

# Properties
- Whichever developer pushes their changes to the central repository first can do so without conflict; any other developer whose local history has since diverged from it must first integrate that work into their own before they are able to push, so as not to overwrite it.
