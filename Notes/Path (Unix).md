# Definition
> [!definition] Path (Unix)[^1]
> A path (or pathname) identifies a file or directory's location within the Unix directory hierarchy, a tree structure that starts at the root directory (/), with / also serving as the directory separator.

# Properties
- An absolute (full) path starts with /, such as /usr/lib.
- A relative path does not begin with /.
- Two dots (..) refer to the parent of a directory.
- One dot (.) refers to the current directory.
