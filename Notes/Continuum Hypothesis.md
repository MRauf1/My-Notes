# Definition
> [!info] Continuum Hypothesis[^1]
> If $\operatorname{card}(X) \leq \mathfrak{c}$, then either $X$ is [[Countable Set|countable]] or $\operatorname{card}(X) = \mathfrak{c}$. Equivalently, there is no set whose [[Set Cardinality|cardinality]] lies strictly between $\operatorname{card}(\mathbb{N})$ and $\mathfrak{c}$; i.e. $2^{\aleph_0} = \aleph_1$.

Since $\operatorname{card}(\Omega) \leq \operatorname{card}(X)$ for every uncountable $X$, where $\Omega$ is the [[Set of Countable Ordinals]], the hypothesis is equivalent to $\operatorname{card}(\Omega) = \mathfrak{c}$.[^2]

Folland's advice: if the answer to a question depends on the continuum hypothesis, one should give up and ask a different question.[^2]

# Properties
- It is the converse of "$\operatorname{card}(X) \geq \mathfrak{c} \implies X$ uncountable" (see [[Cardinality of the Continuum]]).[^3]
- Independence: Gödel (1940) showed CH is consistent with ZFC (via the constructible universe $L$), and Cohen (1963) showed $\neg$CH is consistent with ZFC (via forcing), assuming ZF is consistent. Hence CH can be neither proved nor disproved from ZFC.[^2]
- Status today: still no consensus. Gödel and Cohen both suspected CH is false; modern strong forcing axioms (e.g. the Proper Forcing Axiom) imply $\mathfrak{c} = \aleph_2$, while Woodin's "Ultimate $L$" program points toward CH. Neither has become standard.
- Same logical status as the [[Axiom of Choice]] relative to ZF; compare [[Gödel's Incompleteness Theorem]].
