# Definition

> [!info] Definition (Digital Image)[^1]
> An image can be abstracted as a function $I(x, y) : R \rightarrow V$, where $R \subset \mathbb{R}^2$ is a rectangular domain and $V$ is the set of possible pixel values. For an idealized grayscale image, $V = \mathbb{R}^+$ (brightness only); for an idealized color image with red, green, and blue values, $V = (\mathbb{R}^+)^3$.

# Properties
- Physically, this abstracts the two-dimensional distributions of light energy that images represent: the light emitted from a monitor, the light falling on a camera's image sensor, or the light reflected from a printed page—almost always over a rectangular area.
