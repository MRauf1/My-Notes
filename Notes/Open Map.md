# Definition

> [!info] Definition 1 (Open Map)[^1]
> A mapping $f: X \rightarrow Y$ between [[Metric Space|metric spaces]] is open if $f(V)$ is an [[Open Set]] in $Y$ whenever $V$ is an [[Open Set]] in $X$.

Open maps send open sets forward ([[Image|images]]), whereas [[Continuous Function|continuous]] maps pull open sets back ([[Preimage|preimages]]; [[Continuous Function on Metric Space Theorem]]).

# Properties
- Every continuous open mapping of $\mathbb{R}$ into $\mathbb{R}$ is [[Monotonic Function|monotonic]] (in fact strictly monotonic).[^1]
- A continuous [[Bijective Function|bijection]] has a continuous inverse if and only if it is open.[^2]
