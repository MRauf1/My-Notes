# Definition
> [!definition] Vim Editing Grammar[^1]
> [[Vim]] editing commands follow the general form `[count] operator [count] motion`, combining an operator with a motion or text object so the same action can work at the scope of a character, word, line, or larger unit.

# Properties
- Executed from [[Vim]]'s Normal mode.

[^1]: [Linux Journey: Advanced Text-Fu](https://labex.io/linuxjourney/courses/advanced-text-fu)
