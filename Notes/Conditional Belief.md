# Definition
> [!info] Conditional Belief[^1]
> An agent $S$'s conditional belief at time $t$ in [[Proposition|proposition]] $H$ given $E$ is defined using [[Conditional Probability|conditional probability]] as
> $$
> \begin{align}
> P_{S,t}(H \mid E) = \frac{P_{S,t}(H \& E)}{P_{S,t}(E)}
> \end{align}
> $$
> i.e., the proportion of the agent's $E$-possibilities that are also $H$-possibilities.

# Properties
- Contrasts with unconditional [[Credence|credence]], which this analysis allows an agent's conditional beliefs to be derived from.
- Can be decomposed as $P(H \mid E) = P(H) \times \frac{P(E \mid H)}{P(E)}$, where $P(H)$ is called the prior and $\frac{P(E \mid H)}{P(E)}$ the multiplier, following [[Bayes' Theorem]]; $P(H \mid E) \gtrless P(H)$ according to whether this multiplier is $\gtrless 1$.
