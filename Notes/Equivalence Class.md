# Definition

> [!info] Definition 1 (Equivalence Class)[^1]
> For an [[Equivalence Relation]] $R$, the [[Subset]] of all elements related to one another under the [[Equivalence Relation]] is called the equivalence class.
> The [[Set]] of equivalence classes create a [[Partition]] of the [[Set]] $A$.
> The equivalence class of element $x \in A$ with respect to the [[Equivalence Relation]] $R$ is denoted as $[x]_R = \{y \in A | yRx\}$.

# Properties
- For every $x \in A$, $x \in [x]_R$
- For every $x, y \in A$, $y \in [x]_R$ if and only if $[y]_R = [x]_R$
