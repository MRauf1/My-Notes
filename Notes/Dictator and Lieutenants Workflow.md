# Definition
> [!info] Dictator and Lieutenants Workflow[^1]
> The dictator and lieutenants workflow is a variant of the [[Integration-Manager Workflow]] used by very large projects with hundreds of collaborators, in which different integration managers, called lieutenants, are each responsible for merging contributions into a specific part of the project.

# Properties
- All lieutenants report to a single overall integration manager, the benevolent dictator, who pushes the merged result from their own repository into a reference repository that every collaborator pulls from.
