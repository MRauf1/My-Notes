# Definition

> [!info] Definition 1 (Limaçon)[^1]
> A limaçon is the graph in the [[Polar Coordinate System]] of
> $$
> \begin{align}
> r = a + b\cos(\theta) \quad \text{or} \quad r = a + b\sin(\theta), \qquad a, b \neq 0
> \end{align}
> $$

# Types
Its shape depends on the ratio $|a| / |b|$:
- $|a| < |b|$: inner loop ($r$ changes sign, so the curve passes through the origin twice).
- $|a| = |b|$: [[Cardioid]] (cusp at the origin).
- $|b| < |a| < 2|b|$: dimpled.
- $|a| \geq 2|b|$: convex.

# Properties
- The $\cos$ form is symmetric about the polar axis ($\theta \mapsto -\theta$), and the $\sin$ form about the line $\theta = \frac{\pi}{2}$.
- Converted to rectangular coordinates via $r^2 = x^2 + y^2$, $x = r\cos\theta$ ([[Cartesian and Polar Coordinate System Change]]), e.g. $r = a + b\cos\theta$ becomes $x^2 + y^2 = a r + b x$.
