# Definition
> [!info] Pseudoterminal[^1]
> A pseudoterminal is a [[Pseudodevice]] that presents the I/O interface of a real [[Terminal (Unix)|terminal]] to a user process, but is connected by the kernel to a piece of software, such as a terminal-emulator window, instead of physical hardware.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=76&annotation=T436N4UJ)
