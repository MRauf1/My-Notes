# Definition
> [!info] Git Commit Message Convention[^1]
> A well-formed [[Git]] commit message begins with a concise summary line of no more than about 50 characters, followed by a blank line, followed by a more detailed explanatory body.

# Properties
- The summary line should be written in the imperative mood, e.g. "Fix bug" rather than "Fixed bug" or "Fixes bug".
- The detailed body should explain the motivation for the change and contrast the new behavior with the previous one.
