# Definition

> [!info] Definition 1 ([[Graph]] Connected Components)[^1]
> Each connected component of a [[Graph]] $G$ contains the maximal (biggest possible) [[Subgraph]] of $G$ whose [[Vertex]] are all connected to each other. It includes all of these connected [[Vertex]] and the [[Edge]] between them.
> The [[Set]] of connected components forms a [[Partition]] on the [[Set]] of [[Vertex]].

[^1]: [Building Blocks for Theoretical Computer Science](zotero://open-pdf/library/items/5IGT8C55?page=124)
