# Definition
> [!info] Performance Measure[^1]
> The criterion that defines the standard of success for an [[Agent|agent]]'s behavior in its environment; it assigns a score to any given sequence of environment states.

# Properties
- As a general rule, it is better to design a performance measure according to what one actually wants achieved in the environment, rather than according to how one thinks the agent should behave.
- A [[Rational Agent|rational agent]] selects, for each possible percept sequence, the action expected to maximize this measure.
- An agent's [[Utility Function|utility function]] is an internalization of the performance measure.

[^1]: [Russell and Norvig, 2022, p. 57](zotero://open-pdf/library/items/JZXT5DZQ?page=57&annotation=CWVASCWQ)
