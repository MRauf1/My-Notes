# Definition
> [!info] Centralized Version Control System[^1]
> A centralized version control system (CVCS) is a [[Version Control System]] with a single server that holds all versioned files, from which a number of clients check out files; it was developed so that developers working on separate systems could collaborate with one another.

# Properties
- For many years, this architecture was the standard approach to version control.
