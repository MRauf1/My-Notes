# Definition
> [!info] Agent Function[^1]
> $$
> f : \text{Percept Sequence} \to \text{Action}
> $$
> The mathematical function describing an [[Agent|agent]]'s behavior: it maps any given [[Percept|percept sequence]] to an action.

# Properties
- Implemented, for a physical agent, by an [[Agent Program|agent program]].
- A [[Rational Agent|rational agent]] is one whose agent function selects, for every percept sequence, an action expected to maximize its [[Performance Measure|performance measure]].

[^1]: [Russell and Norvig, 2022, p. 54](zotero://open-pdf/library/items/JZXT5DZQ?page=54&annotation=ZPRQC7R7)
