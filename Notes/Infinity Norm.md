# Definition
> [!info] Definition 1 ($\infty$-Norm)[^1]
> The $\infty$-norm on $\mathbb{R}^n$ or $\mathbb{C}^n$ is defined by
> $$
> \lVert x \rVert_\infty := \max_{1 \leq j \leq n} |x_j|
> $$

The [[Normed Space|norm]] properties follow from those of $|\cdot|$, together with the fact that $\max_{1 \leq j \leq n}(a_j + b_j) \leq \max_{1 \leq j \leq n} a_j + \max_{1 \leq j \leq n} b_j$.

The [[Supremum Norm]] on $C([0,1])$ is the functional analog of the $\infty$-norm.

# Properties
- [[p-Norm]]
- [[Norm Equivalence Inequalities (Finite-Dimensional)]]
- The unit ball of the $\infty$-norm on $\mathbb{R}^2$ is a square (not a [[Strictly Convex Space|strictly convex]] set — it contains line segments on its boundary).
