# Definition

> [!info] Definition 1 (Smallest Element)[^1]
> Let $R$ be a [[Partial Order]], $B \subseteq A$, $b \in B$. Then $b$ is the smallest element of $B$ if for all $x \in B$, $bRx$.

Smallest element is the element that is smaller than all of the other elements. There can be at most 1 smallest element in a [[Partial Order]].

The reverse of this is the [[Relation Largest Element]].

In [[Total Order]], [[Relation Smallest Element]] and [[Relation Minimal Element]] are the same.

# Properties
- If $B$ has a smallest element, then the smallest element is unique.
- If $B$ has a smallest element, then the smallest element is the only [[Relation Minimal Element]].
