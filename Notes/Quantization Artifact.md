# Definition

> [!info] Definition (Quantization Artifact)[^1]
> A quantization artifact, or banding, is an [[Image Artifact]] that occurs when limited pixel precision forces rounding to the nearest representable value, introducing visible jumps in intensity or color.

# Properties
- Particularly noticeable in animation and video, where bands that are not objectionable in a still image become very visible as they move back and forth.
- Also called banding.
- A type of [[Image Artifact]].
