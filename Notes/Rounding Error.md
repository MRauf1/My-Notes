# Definition

> [!info] Definition 1 (Rounding [[Error]])[^1]
> The difference between the result produced by a given algorithm using exact arithmetic and the result produced by the same algorithm using finite-precision, rounded arithmetic.

[[Error]] from [[Rounding]], due to inexactness in the representation of real numbers and arithmetic operations upon them.[^2] Rounding error tends to dominate in purely algebraic problems with finite solution algorithms.[^3]
