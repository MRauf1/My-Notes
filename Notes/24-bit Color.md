# Definition

> [!info] Definition (24-bit Color)[^1]
> In 24-bit color, each of the three [[RGB Color Space|RGB]] components is stored as an integer between $0$ and $255$ (one byte), giving $256$ possible levels per primary color and $24$ bits ($3$ bytes) per pixel in total.

# Properties
- The most common integer range for quantized display input is $0$–$255$, held in 8 bits.
- Extended to $32$ bits per pixel by adding an [[Alpha Channel]], forming an RGBA image.
