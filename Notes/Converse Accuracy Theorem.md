# Definition
> [!info] Converse Accuracy Theorem[^1]
> If a set of beliefs satisfies the rules of [[Probabilism|probability]], then it is not [[Accuracy Dominance|accuracy dominated]] by one that doesn't.

# Properties
- Converse of the [[Accuracy Theorem]]; the accuracy analogue of the [[Converse Dutch Book Theorem]].
- Ensures that holding dominated beliefs is avoidable, which premise P1 of the [[Accuracy Argument]] requires.

[^1]: [A Critical Introduction to Formal Epistemology](zotero://open-pdf/library/items/9XYCZDPF?page=48)
