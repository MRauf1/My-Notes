# Definition
> [!definition] PAM Control Argument[^1]
> The control argument is the part of a [[Pluggable Authentication Modules (PAM)|PAM]] configuration line that determines how the success or failure of that line's action affects the lines that follow, since PAM's configuration lines stack.

# Properties
- Comes in two kinds of syntax: a simple syntax and a more advanced syntax.[^2]
