# Definition

> [!abstract] Theorem 1 ([[Upper Triangular Matrix]] [[Lower Triangular Matrix]] Lemma)[^1]
> Suppose that $T \in \mathcal{L}(V)$ and that $\mathcal{B} = (v_1, \dots, v_n)$ is a [[Basis]] of $V$. Then
> 1) $[T]_{\mathcal{B}}$ is [[Upper Triangular Matrix]] if and only if for each $j = 1, \dots, n$, $Tv_j \in \langle v_1, \dots, v_j \rangle$.
> 2) $[T]_{\mathcal{B}}$ is [[Lower Triangular Matrix]] if and only if for each $j = 1, \dots, n$, $Tv_j \in \langle v_j, \dots, v_n \rangle$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=239)
