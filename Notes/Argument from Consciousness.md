# Definition
> [!info] Argument from Consciousness[^1]
> The objection (due to Geoffrey Jefferson) that a machine cannot be said to think unless it actually feels and is aware of its thoughts, rather than merely producing the outward signs of thinking. In its most extreme form, the only way to be sure a machine thinks is to *be* the machine and feel oneself thinking; by the same reasoning, the only way to know a person thinks is to be that person. This is the solipsist point of view.

# Properties
- One of the [[Objections to Machine Intelligence]].
- Turing's rebuttal: taken to its conclusion the argument collapses into solipsism, which would deny that we can know other *people* think. Rather than argue this point continually, we adopt the polite convention that everyone thinks, and the same behavioural standard ([[Turing Test]]) can be extended to machines.
- Turing concedes there is genuine mystery about [[Consciousness]], e.g. a paradox in any attempt to localise it, but holds that these mysteries need not be solved before answering whether machines can pass the imitation game.[^2]
- Those who hold the argument can usually be persuaded to abandon it rather than accept solipsism, e.g. when a machine sustains a convincing viva-voce style dialogue.
