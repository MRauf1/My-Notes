# Definition
> [!info] Live Image (Linux)[^1]
> A live image is a bootable system image — often the same image used for installation — used as the first recourse for repairing a broken system, alongside dedicated rescue images.

# Properties
- Common repair tasks include checking filesystems after a crash, resetting a forgotten root password, fixing critical configuration files such as `/etc/fstab` and `/etc/passwd`, and restoring from backups.[^2]
- Preferred over [[Single-User Mode|single-user mode]], since it provides a fuller working environment (networking, a GUI, a reliable terminal).
