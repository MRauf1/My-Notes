# Definition

> [!abstract] Theorem 1 ([[Diagonalizable Matrix]] [[Diagonalizable Linear Map]])[^1]
> Let $T \in \mathcal{L}(V)$, let $\mathcal{B}$ be a [[Basis]] for $V$, and let $A = [T]_{\mathcal{B}}$. Then $A$ is [[Diagonalizable Matrix]] if and only if $T$ is [[Diagonalizable Linear Map]].

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=224)
