# Definition
> [!info] Topic Branch[^1]
> A topic branch is a short-lived [[Branch (Git)|branch]] created and used for a single particular feature or a single body of related work, and useful in projects of any size.

# Properties
- Isolating each piece of work in its own topic branch means that, if a contribution is rejected, it can simply be discarded without affecting any other work, and each topic can be [[Rebasing (Git)|rebased]] independently if the branch it will be integrated into has moved on, without interfering with other topic branches.
