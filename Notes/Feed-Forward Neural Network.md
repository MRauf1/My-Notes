# Definition
> [!info] Feed-Forward Neural Network[^1]
> A neural network whose connections form an acyclic graph, i.e., one with no loops.

# Properties
- [[Shallow Neural Network|Shallow]] and [[Deep Neural Network|deep]] [[Multilayer Perceptron|MLPs]] are feed-forward; if every element in one layer connects to every element in the next, the network is additionally **fully connected** ([[Linear Layer]]).

[^1]: [Prince, p. 35](zotero://open-pdf/library/items/BWT7FYX5?page=49&annotation=LV3HF7ZK)
