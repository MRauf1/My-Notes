# Definition

> [!info] Definition 1 ([[Graph]] Chromatic Number)[^1]
> Chromatic number of [[Graph]] $G$ is the smallest number of colors needed to [[Graph Coloring|color]] $G$.
> It is denoted as $\chi(G)$.

[^1]: [Building Blocks for Theoretical Computer Science](zotero://open-pdf/library/items/5IGT8C55?page=132)
