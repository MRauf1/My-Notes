# Definition
> [!info] Reserve Clause[^1]
> (*Hupexhairesis*) The Stoic practice of undertaking any action "with reservation": wanting the outcome only conditionally, together with the unconditional aim of keeping one's will in accord with nature, e.g. "I want to bathe *and* to keep my will in accord with nature."

# Properties
- If the activity is obstructed, one still achieves the second, unconditional aim, provided one doesn't resent what happens.[^1]
- Inclinations should be used "with a light touch, with reservation, and with detachment", and every inclination should be conditional.[^2]
- Before any activity, remind yourself of its characteristic features (e.g. what happens at public baths), so as not to be surprised.[^1]
- An application of the [[Dichotomy of Control]] to the second of the [[Three Disciplines (Epictetus)]].
