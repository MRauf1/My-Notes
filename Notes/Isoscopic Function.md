# Definition
> [!info] Definition 1 (Isoscopic Function)[^1]
> A function $f: M_n(\mathbb{F}) \to \mathbb{F}$ is isoscopic if $f(A) = 0$ whenever $A$ has two identical columns.

> [!abstract] Lemma 2 (Lemma 6.1)[^2]
> Suppose $D: M_n(\mathbb{F}) \to \mathbb{F}$ is an isoscopic [[Multilinear Function]]. If $A \in M_n(\mathbb{F})$ is singular, then $D(A) = 0$.

Lemma 2 is the key step toward the [[Determinant]]: it shows that any isoscopic multilinear function already detects singularity, before the stronger [[Alternating Multilinear Function|alternating]] property is even imposed.
