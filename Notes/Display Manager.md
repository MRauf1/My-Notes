# Definition
> [!definition] Display Manager[^1]
> A display manager is the program that starts the [[X Window System|X server]] and puts a login box on the screen; once the user logs in, it starts a set of clients, such as a [[Window Manager|window manager]] and file manager, so the machine becomes usable.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=325&annotation=USYW9448)
