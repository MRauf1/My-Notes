# Definition

> [!abstract] Theorem 1 (Heine-Borel Theorem)[^1]
> [[Subset]] $E$ of $\mathbb{R}^k$ is [[Compact Set]] if and only if $E$ is [[Closed Set]] and [[Bounded Set]].

> [!abstract] Theorem 2 (Third Equivalent Condition)[^2]
> Let $E \subseteq \mathbb{R}^k$. Then $E$ is [[Closed Set|closed]] and [[Bounded Set|bounded]], if and only if $E$ is [[Compact Set|compact]], if and only if every infinite [[Subset]] of $E$ has a [[Limit Point]] that lies in $E$.

# Properties
- In a general [[Metric Space]], compact $\implies$ closed and bounded always holds, but closed and bounded $\not\implies$ compact (e.g. an infinite set with the discrete metric). The full metric-space characterization is complete and [[Totally Bounded|totally bounded]]: see [[Compact Metric Space]].[^3]
