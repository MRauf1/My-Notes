# Definition

The mode of a dataset with $n$ datapoints is the number with the highest [[Frequency|frequency]].[^1]

A mode of the distribution of a [[Random Variable]] is a value of $x$ that maximizes the pdf/pmf. If there is only one such $x$, it is called the mode of the distribution.[^2]

# Properties
- Not invariant under transformation: for a nonlinear one-to-one $g$, the mode of $g(X)$ is in general not $g$ of the mode of $X$, because the pdf picks up the Jacobian factor $|dx/dy|$ ([[Random Variable Transformation]]). The [[Median]], defined through probabilities of events, is invariant under monotone $g$. This is why MAP estimates depend on the parametrization ([[Maximum Likelihood vs Maximum a Posteriori Estimation]]).
