# Definition

The mode of a dataset with $n$ datapoints is the number with the highest [[Frequency|frequency]].[^1]

A mode of the distribution of a [[Random Variable]] is a value of $x$ that maximizes the pdf/pmf. If there is only one such $x$, it is called the mode of the distribution.[^2]
