# Definition
> [!info] Lightweight Tag[^1]
> A lightweight tag is a [[Git Tag]] that behaves like a branch that never changes: it is simply a pointer to a specific commit, with no additional information stored.

[^1]: [Pro Git](zotero://open-pdf/library/items/Y53JUJJW?page=62&annotation=3JLUP57S)
