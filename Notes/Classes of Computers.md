# Definition
> [!info] Classes of Computers[^1]
> Computers are commonly grouped into classes according to their scale, cost, and typical use.

# Types
- Personal computer (PC) — a computer designed for use by an individual, usually with a graphics display, keyboard, and mouse.
- Server — a computer used for running larger programs for multiple users, often simultaneously, typically accessed only via a network.
- Supercomputer — a class of computer with the highest performance and cost, configured as servers and costing tens to hundreds of millions of dollars.
- Embedded computer — a computer inside another device, used for running one predetermined application or collection of software.
- Personal mobile device (PMD) — a small wireless device that connects to the Internet, relies on batteries for power, and installs software as downloaded apps (e.g. smartphones and tablets).

# Properties
- Cloud computing refers to large collections of servers that provide services over the Internet, with some providers renting dynamically varying numbers of servers as a utility.
- Software as a Service (SaaS) delivers software and data as a service over the Internet, usually via a thin client program such as a browser, instead of binary code installed and run wholly on the local device.
