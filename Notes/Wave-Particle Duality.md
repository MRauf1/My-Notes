# Definition
> [!info] Wave-Particle Duality[^1]
> Every physical entity exhibits both wave-like and particle-like behavior; there is no fundamental distinction between a "wave" description and a "particle" description of the same underlying phenomenon, only a difference in which aspect is more evident under given conditions.

# Properties
- At low frequency, the wave aspect (e.g. a classical [[Electromagnetic Field]]) is the more useful approximate description.
- At high frequency, the particle aspect (e.g. the [[Photon]]) becomes more evident with typical measuring apparatus.
- Reconciled quantitatively by quantum mechanics, in particular via the [[Heisenberg Uncertainty Principle]].
- Unifies what were previously separate field/wave theories and particle theories into a single quantum-mechanical framework.

[^1]: [The Feynman Lectures on Physics, Vol. I, Ch. 2: Basic Physics](https://www.feynmanlectures.caltech.edu/I_02.html)
