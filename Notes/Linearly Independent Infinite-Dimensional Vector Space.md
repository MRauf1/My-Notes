# Definition

> [!abstract] Theorem 1 ([[Linearly Independent]] [[Infinite-Dimensional Vector Space]])[^1]
> $V$ contains a [[Linearly Independent]] list of $n$ [[Vector]] for every $n \geq 1$ if and only if $V$ is [[Infinite-Dimensional Vector Space]].
