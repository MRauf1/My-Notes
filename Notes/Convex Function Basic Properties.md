# Definition

- $f$ is [[Convex Function]] if and only if $f'(x) \leq f'(y)$ for all $a < x < y < b$
- $f$ is [[Strictly Convex Function]] if and only if $f'(x) < f'(y)$ for all $a < x < y < b$
- $f$ is [[Convex Function]] if and only if $f''(x) \geq 0$ for all $a < x < b$
- $f$ is [[Strictly Convex Function]] if and only if $f''(x) > 0$ for all $a < x < b$
