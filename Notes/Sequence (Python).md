# Definition
> [!info] Sequence (Python)[^1]
> A positionally ordered collection of objects, indexed from the front starting at offset 0, that supports both direct indexing and [[Slicing (Python)|slicing]].

# Properties
- Also supports negative indexing: positive indexes count forward from the left, and negative indexes count backward from the right, formally by adding the negative index to the sequence's length to get an equivalent positive offset[^2].
- Any Python expression — a literal, a variable, or a computed value — may be used inside the indexing brackets, not just a hardcoded number[^3].
- [[Python String]], [[Python List]], and [[Python Tuple]] are the three core sequence types; unlike [[Python Dictionary|dictionaries]] and [[Python Set|sets]], they share this common set of positional operations.
