# Definition
> [!info] Computable Number[^1]
> Informally, a number is computable if its decimal expansion can be written down by a machine. Formally, a sequence is *computable* if it can be computed by a circle-free [[Turing Machine|computing machine]], and a real number is *computable* if it differs by an integer from the number computed by a circle-free machine.

# Properties
- The computable numbers are a very large class, in many ways similar to the [[Real Number|real numbers]], yet they are enumerable (countable): each machine has a finite description, so there are only countably many machines. Hence almost all real numbers are not computable.[^2]
- The computable numbers do not include all *definable* numbers: a diagonal argument over the enumeration of circle-free machines defines a number that no machine computes.[^2]
- Correctly applying such diagonal arguments yields conclusions superficially similar to [[Gödel's Incompleteness Theorem|Gödel's incompleteness theorem]] (e.g. that no machine can decide whether an arbitrary machine is circle-free).[^2]
- The number-theoretic counterpart of the computable functions in [[Computability]].
