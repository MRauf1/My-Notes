# Definition
> [!info] System (Signal Processing)[^1]
> A process/function $f$ that transforms an input [[Signal (Signal Processing)|signal]] $\ell_{\text{in}}$ into an output signal:
> $$
> \begin{align}
> \ell_{\text{out}} = f(\ell_{\text{in}})
> \end{align}
> $$

![[Hierarchy of Systems.png]]

# Types
- [[Linear System (Signal Processing)|Linear system]]
- [[Shift-Invariant System|Linear translation invariant (LTI) system]]

# Properties
- Nested hierarchy: all functions $\supset$ differentiable $\supset$ linear $\supset$ LTI.
- Not to be confused with the C library function [[System (Function)]].
