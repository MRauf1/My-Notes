# Definition

> [!abstract] Theorem 1 ([[Continuous Function]] on [[Metric Space]] Theorem)[^1]
> [[Function]] $f: S_1 \rightarrow S_2$ is continuous on $S_1$ if and only if $f^{-1}(U)$ is [[Open Set]] [[Subset]] of $S_1$ for every [[Open Set]] [[Subset]] $U$ of $S_2$.

Also stated for mappings $f: X \rightarrow Y$ of [[Metric Space|metric spaces]] in terms of the [[Preimage]] $f^{-1}(V)$; a very useful characterization of continuity.[^2]

> [!abstract] Corollary 2 (Closed Set Characterization)[^3]
> A mapping $f$ of a [[Metric Space]] $X$ into a [[Metric Space]] $Y$ is continuous if and only if $f^{-1}(C)$ is [[Closed Set|closed]] in $X$ for every closed set $C$ in $Y$.

# Properties
- Contrast with [[Open Map]], which maps open sets forward.
