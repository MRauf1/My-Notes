# Definition
> [!info] Dynamic Typing (Python)[^1]
> A typing model, used by Python, that keeps track of an [[Object (Python)|object's]] type automatically at runtime instead of requiring declaration code from the programmer.

# Properties
- Complements [[Strong Typing (Python)|strong typing]]: Python tracks types for you, but still only allows operations valid for an object's actual type.
- Because types live with objects rather than with [[Variable (Python)|variable names]], a variable can be reassigned to reference objects of different types over its lifetime without any declaration.
