# Definition

> [!abstract] Theorem 1 (LUP Decomposition)[^1]
> Like [[LU Decomposition]], but there is an additional [[Permutation Matrix]] $P$, which is a product of [[Elementary Matrix]]/[[Row Operations]] R3, such that $PA = LU$.

Every [[Matrix]] has an LUP Decomposition.
