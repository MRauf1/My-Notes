# Definition
> [!info] Set of Countable Ordinals[^1]
> There is an uncountable [[Well-Ordered Set|well ordered set]] $\Omega$ such that the [[Initial Segment]] $I_x$ is [[Countable Set|countable]] for each $x \in \Omega$. If $\Omega'$ is another set with the same properties, then $\Omega$ and $\Omega'$ are [[Order Isomorphism|order isomorphic]]. This essentially unique $\Omega$ is the set of countable ordinals.[^2]

> [!info] First Uncountable Ordinal[^3]
> Adjoin an element $\omega_1$ to form $\Omega^* = \Omega \cup \{\omega_1\}$, ordered by declaring $x < \omega_1$ for all $x \in \Omega$. $\omega_1$ is called the first uncountable ordinal.

In standard set theory $\omega_1$ is identified with $\Omega$ itself (an ordinal is the set of its predecessors), so the usual notation for $\Omega$ is $\omega_1$.

# Properties
> [!abstract] Proposition (Countable Subsets are Bounded)[^4]
> Every countable subset of $\Omega$ has an [[Relation Upper Bound|upper bound]] in $\Omega$.

- This is what makes $\Omega$ useful: transfinite constructions indexed by $\Omega$ (e.g. building the [[Sigma-Field|$\sigma$-algebra]] generated by a family) close up under countable operations at some stage $< \omega_1$.
- $\operatorname{card}(\Omega) \leq \operatorname{card}(X)$ for every uncountable $X$; the [[Continuum Hypothesis]] is equivalent to $\operatorname{card}(\Omega) = \mathfrak{c}$.[^5]
