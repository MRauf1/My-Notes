# Definition
> [!info] Spiral Plan (Writing)[^1]
> Halmos's method of writing in which parts are written and rewritten in the order 1, 2, 1, 2, 3, 1, 2, 3, 4, ..., since writing each later part reveals how earlier parts should have been done differently.

# Properties
- Accounts for most of the rewriting a book involves, and the same phenomenon recurs at every scale: chapters, sections, paragraphs, sentences, and words.[^1]
- First step: given subject, audience, outline, and notation, start writing and let nothing stop you; "there is no better incentive for writing a good book than a bad book." A spiral-written first draft backed by a detailed outline is more than half the work.[^1]
- In the first draft, write quickly and violate all rules; when revising, *rewrite* rather than edit, being merciless about changes and especially wholesale omissions: "Rewrite means write again, every word."[^1]
- Indispensable for effective use of "subplots and clues", i.e. foreshadowing later material.[^1]
- A principle of [[Mathematical Writing]]; cf. the [[Circularity of Writing]].

[^1]: [Halmos, How to Write Mathematics](zotero://open-pdf/library/items/9Q96EPCM?page=1)
