# Definition
> [!info] Atomic Commit[^1]
> An atomic commit is a commit that represents a single, logically separate changeset, rather than bundling multiple unrelated changes together.

# Properties
- Keeping each commit atomic makes changes easier for reviewers and collaborators to digest, understand, and, if necessary, selectively integrate or revert.
