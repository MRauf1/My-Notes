# Definition
> [!info] Linear Continuum[^1][^2]
> A [[Set]] $L$ with an order relation $<$ (a [[Strict Total Order]]) is a linear continuum if
> 1. $L$ has the least upper bound property: every nonempty subset of $L$ that is [[Relation Upper Bound|bounded above]] has a [[Relation Least Upper Bound|least upper bound]].
> 2. Between any two elements there is a third: if $x < y$, there exists $z$ such that $x < z < y$.

These are the order properties (7) and (8) of $\mathbb{R}$: they abstract the "no gaps" ([[Completeness Axiom]]) and "no jumps" (no immediate successors, see [[Open Interval in Ordered Set]]) features of the real line, and involve only the order relation, not the algebraic field structure.

# Properties
- $\mathbb{R}$ is a linear continuum; $\mathbb{Q}$ satisfies (2) but not (1); $\mathbb{Z}$ satisfies (1) but not (2).
- The ordered square $[0, 1] \times [0, 1]$ in the [[Dictionary Order]] is a linear continuum.
- In the order topology, linear continua are exactly the ordered sets whose intervals and rays are connected; this is what drives the intermediate value theorem.
