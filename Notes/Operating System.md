# Definition
> [!info] Operating System[^1]
> A supervising program that manages the resources of a computer for the benefit of the programs that run on it, interfacing between a user's program and the hardware.

# Properties
- A type of [[Systems Software]].
- Its [[Kernel (Operating System)|kernel]] is the core piece of software that actually resides in main memory and tells the CPU what to do on the operating system's behalf.
- Provides the operating-system interfaces used, together with the user portion of the [[Instruction Set Architecture]], to define the [[Application Binary Interface]].
