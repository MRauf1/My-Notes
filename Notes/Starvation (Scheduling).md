# Definition
> [!info] Starvation (Scheduling)[^1]
> A condition in which a process is repeatedly passed over by the scheduler and so never actually gets to run.

# Properties
- A hazard of any scheduler that lacks some form of [[Preemptive Scheduling|preemption]], since without it a process already running can indefinitely delay every other ready process.
