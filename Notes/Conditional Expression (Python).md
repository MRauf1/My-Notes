# Definition
> [!info] Conditional Expression (Python)[^1]
> Python's "ternary" expression, `Y if X else Z`, which evaluates to `Y` if `X` is true and to `Z` otherwise, letting an [[If Statement (Python)|if/else]] choice be written as a single expression.
