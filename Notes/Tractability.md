# Definition
> [!info] Tractability[^1]
> A problem is tractable if it can be solved in time that grows polynomially with the size of its instances, and intractable if the time required grows exponentially with instance size.

# Properties
- The theory of [[NP-Complete|NP-completeness]] provides a basis for analyzing tractability: any problem class to which the class of NP-complete problems can be reduced is likely intractable.
- Presupposes [[Computability]]: tractability concerns the efficiency of solving problems already known to be computable.

[^1]: [Russell and Norvig, 2022, p. 27](zotero://open-pdf/library/items/JZXT5DZQ?page=27&annotation=DF6E8XJE)
