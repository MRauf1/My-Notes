# Definition
> [!info] Definition (Primitive)[^1]
> A basic type of geometric object, described by a set of vertices, that a graphics system can handle directly by [[Rasterization]]; more complex objects are converted into primitives before rendering. [[Triangle|Triangles]] are the most commonly used primitive.

# Properties
- Fed into the [[Graphics Pipeline]] from an interactive application or a scene description file; its vertices are transformed during [[Vertex Processing]] before it reaches the rasterizer.

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=174&annotation=U5MIX8AX)
