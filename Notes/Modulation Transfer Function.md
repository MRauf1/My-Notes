# Definition
> [!info] Definition (Modulation Transfer Function)[^1]
> For a [[Shift-Invariant System|shift-invariant]] imaging system whose [[Point Spread Function|pointspread]] (or [[Line Spread Function|linespread]]) function is even-symmetric, the real-valued function of spatial frequency giving the amplitude scale factor the system applies to each harmonic (sinusoidal) input component.

# Properties
- Equals the magnitude of the [[Optical Transfer Function]], and coincides with it exactly when the impulse response is even-symmetric, since an even-symmetric impulse response introduces no phase shift into any harmonic component.
- Describes how strongly the system attenuates contrast at each spatial frequency, with attenuation typically increasing at higher frequencies as optical blur removes fine detail.

[^1]: [Foundations of Vision (Wandell)](zotero://open-pdf/library/items/YYQVJZJ3?page=25&annotation=8NRQF5YN)
