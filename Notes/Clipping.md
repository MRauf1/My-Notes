# Definition

> [!info] Definition (Clipping)[^1]
> Clipping is an [[Image Artifact]] that occurs when encoding an image with fixed-range values: pixels that would otherwise be brighter than the maximum representable value are instead set, or clipped, to that maximum value.

# Properties
- Arises from storing pixels as [[Low Dynamic Range Image|low dynamic range]] values rather than [[High Dynamic Range Image|high dynamic range]] values.
- A type of [[Image Artifact]].

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=68&annotation=6QKT4SFD)
