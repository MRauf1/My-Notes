# Definition

> [!info] Definition 1 (Reflexive [[Relation]])[^1]
> Let $R: A \rightarrow A$ be a [[Relation]]. It is reflexive if for all $x \in A$, $(x, x) \in R$.
> $R$ is reflexive if and only if $I_A \subseteq R$, where $I_A$ is the [[Identity Relation]].

# Types
- [[Reflexive Closure]]

# Properties
- If $R$ is reflexive, so is $R^{-1}$
- If $R_1, R_2$ are reflexive, then so is $R_1 \cup R_2$, $R_1 \cap R_2$, $R_1 \circ R_2$

[^1]: [HOW TO PROVE IT: A Structured Approach, Second Edition](zotero://open-pdf/library/items/THI2Q4PN?page=198)
