# Definition

For a 2D [[Triangle]], the [[Barycentric Coordinates]] $(\alpha, \beta, \gamma)$ of a point $\mathbf{p}$ can be computed directly from [[Signed Area of a Triangle|signed areas]], since a signed area is well-defined for 2D points.

# Properties

## Geometric Interpretation
Each barycentric coordinate is the signed scaled [[Distance]] from $\mathbf{p}$ to the line through the triangle side opposite the corresponding vertex.[^1]
