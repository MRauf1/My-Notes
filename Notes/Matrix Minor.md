# Definition
> [!info] Definition 1 (Matrix Minor)[^1]
> Let $A \in M_n(\mathbb{F})$ for $n \geq 2$. For each $1 \leq i, j \leq n$, $A_{ij} \in M_{n-1}(\mathbb{F})$ denotes the $(n-1) \times (n-1)$ matrix obtained by removing the $i$th row and $j$th column from $A$.
