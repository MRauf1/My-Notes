# Definition
> [!info] ThreadSanitizer[^1]
> A tool from Google, built into clang and gcc, that helps detect [[Data Race|race conditions]] in a program at runtime.

# Properties
- Running a program compiled with ThreadSanitizer (tsan) slows it down.
- Complements [[Undefined Behavior Sanitizer]] as a runtime checking tool built into the [[Compiler|compiler]] toolchain.

[^1]: [Systems Programming](zotero://open-pdf/library/items/8Y3AE875?page=30&annotation=ERLMSL7Q)
