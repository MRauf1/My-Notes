# Definition

> [!abstract] Theorem 1 ([[Finite-Dimensional Vector Space]] [[Vector Subspace]] [[Dimension]])[^1]
> Suppose that $V$ is a [[Finite-Dimensional Vector Space]] and $U$ is a [[Vector Subspace]] of $V$. Then
> 1) $U$ is [[Finite-Dimensional Vector Space]]
> 2) $dim(U) \leq dim(V)$
> 3) If $dim(U) = dim(V)$, then $U = V$

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=188)
