# Definition
> [!definition] Kernel Space[^1]
> Kernel space is the area of main memory that only the kernel can access.

# Properties
- Occupied by the [[Kernel (Operating System)|kernel]] running in [[Kernel Mode]].
- Contrasts with [[User Space]].
- Is a subdivision of [[Main Memory]].

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=27&annotation=NBSDE75L)
