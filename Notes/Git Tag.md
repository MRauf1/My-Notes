# Definition
> [!info] Git Tag[^1]
> A tag is a [[Git]] object that marks a specific commit, typically to denote a release point in a project's history.

# Types
- [[Lightweight Tag]]
- [[Annotated Tag]]

# Properties
- Tags are not transferred to a remote repository automatically; they must be explicitly pushed before other clones of the [[Remote Repository (Git)|repository]] can see them.
