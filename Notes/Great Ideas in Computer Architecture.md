# Definition
> [!info] Great Ideas in Computer Architecture[^1]
> A set of recurring design ideas that computer architects reuse across hardware and software to improve performance, simplify design, and increase dependability.

# Types
- [[Moore's Law]] — design for the exponential growth of integrated circuit resources.
- [[Abstraction]] — use abstraction to simplify design.
- [[Make the Common Case Fast]] — optimize for the frequent case rather than the rare one.
- Performance via parallelism — get more performance by performing operations at the same time (see [[Multicore Microprocessor]]).
- Performance via pipelining — a specific form of parallelism in which overlapping stages process different instructions simultaneously.
- [[Speculative Execution]] — performance via prediction: guess and start working before knowing the answer for sure.
- [[Memory Hierarchy]] — balance the conflicting demands of memory speed, size, and cost with a hierarchy of memories.
- [[Dependability via Redundancy]] — make systems dependable by including redundant components.
