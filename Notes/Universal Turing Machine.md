# Definition
> [!info] Universal Turing Machine[^1]
> A single [[Turing Machine]] $\mathcal{U}$ which can be used to compute any computable sequence: supplied with a tape on whose beginning is written a standard description of any computing machine $\mathcal{M}$, $\mathcal{U}$ computes the same sequence as $\mathcal{M}$.

# Properties
- Turing gave an explicit table of the behaviour of such a machine, proving its existence constructively.[^2]
- Establishes that a fixed machine can simulate any other given its description as data, the theoretical basis of the stored-program computer.
- In [[Intelligent Machinery (Turing)|Intelligent Machinery]], Turing proposed that education organises the infant cortex, an [[Unorganized Machine|unorganized machine]], into something like a universal machine ([[Discipline and Initiative]]).
- Underlies the definition of [[Computable Number|computable numbers]] and [[Computability]] as a machine-independent notion.
