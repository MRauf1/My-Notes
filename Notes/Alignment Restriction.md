# Definition
> [!info] Alignment Restriction[^1]
> A requirement that data be aligned in memory on natural boundaries. In MIPS, words must start at [[Memory Address|addresses]] that are multiples of 4.

# Properties
- Many architectures impose this restriction, since it simplifies the hardware needed to access a [[Word (Computer Architecture)|word]] in a single memory operation.
