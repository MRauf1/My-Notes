# Definition

> [!abstract] Theorem 1 ([[Rank-Nullity Theorem]] [[Injective Function]] [[Surjective Function]] [[Linear Map Isomorphism]])[^1]
> Suppose that $T \in \mathcal{L}(V, W)$. If $dim(V) = dim(W)$, then the following are equivalent:
> 1) $T$ is [[Injective Function]].
> 2) $T$ is [[Surjective Function]].
> 3) $T$ is [[Linear Map Isomorphism]].
