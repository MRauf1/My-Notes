# Definition
> [!info] Cognitive Load (Software Design)[^1]
> A manifestation of [[Software Complexity]] measuring how much a developer needs to know and keep track of in order to complete a task. Higher cognitive load makes a developer more prone to introducing bugs.

# Properties
- Sometimes writing more lines of code actually reduces cognitive load, so minimizing the amount of code touched (as in [[Change Amplification]]) is not always the right tradeoff.
- Reduced by hiding or eliminating information the developer does not need, as in [[Information Hiding]], and by removing [[Obscurity (Software Design)|obscurity]].
- Reduced by keeping names precise and consistent, see [[Naming (Software Design)]].

[^1]: [A Philosophy of Software Design](zotero://open-pdf/library/items/283RR677?page=1)
