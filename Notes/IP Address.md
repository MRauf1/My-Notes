# Definition
> [!definition] IP Address[^1]
> An IP address is the numeric address, of the form `a.b.c.d` (a dotted-quad sequence under [[IPv4]]), that identifies a host on the Internet.

# Properties
- Like a postal address: to communicate with another host, a machine must know that host's IP address.[^2]
- Should be unique across the entire Internet, though private networks and [[Network Address Translation (NAT)|NAT]] complicate this in practice.[^1]
- A host attached to more than one [[Subnet|subnet]] has at least one IP address per subnet.[^1]
