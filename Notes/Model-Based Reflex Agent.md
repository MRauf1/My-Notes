# Definition
> [!info] Model-Based Reflex Agent[^1]
> An [[Agent Program|agent program]] that maintains an internal state, dependent on the percept history, reflecting at least some of the unobserved aspects of the current state, using a [[Transition Model]] and a [[Sensor Model]] to keep track of the world.

# Properties
- The most effective way to handle partial observability ([[Observability (Task Environment)|see observability]]) is for the agent to maintain such an internal state.
