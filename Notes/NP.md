# Definition

> [!info] Definition 1 (NP)[^1]
> Group of problems requiring [[Exponential Function]] time, but no one has proved whether a [[Polynomial Function]] time algorithm exists.
> The solution to these problems can be checked in [[Polynomial Function]] time.
