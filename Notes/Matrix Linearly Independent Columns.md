# Definition

> [!abstract] Theorem 1 ([[Matrix]] [[Linearly Independent]] Columns)[^1]
> The columns of a [[Matrix]] $A \in M_{m, n}(\mathbb{F})$ are [[Linearly Independent]] if and only if $x = 0$ is the only solution of the $m \times n$ [[Linear System of Equations]] $Ax = 0$. That is, the columns of $A$ are [[Linearly Independent]] if and only if $ker(A) = \{0\}$.
