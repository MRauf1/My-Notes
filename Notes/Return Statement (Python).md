# Definition
> [!info] Return Statement (Python)[^1]
> The statement that ends a [[Function (Python)|function]] call and sends a result back to its caller, becoming the value of the call expression; an optional expression supplies the result, and omitting it (or omitting `return` entirely) sends back [[None (Python)|None]] by default.
