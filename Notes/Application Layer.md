# Definition
> [!info] Application Layer[^1]
> Layer 7 of the [[OSI Model]], dealing with application-level interfaces: software above this layer can treat the network purely as a way of communicating with another computer — potentially secured, and with the session able to reconnect — ignoring everything below it.

[^1]: [Systems Programming](zotero://open-pdf/library/items/8Y3AE875?page=266&annotation=8XJE5TLX)
