# Definition
> [!info] Agent[^1]
> Anything that can be viewed as perceiving its environment through sensors and acting upon that environment through actuators.

# Properties
- An agent's behavior is completely described by its [[Agent Function|agent function]], which maps any given [[Percept|percept sequence]] to an action.
- Implemented as an [[Agent Program|agent program]] running on a physical architecture: agent = architecture + program.
- A [[Rational Agent|rational]] agent selects actions to maximize its [[Performance Measure|performance measure]] given its percept sequence and prior knowledge.
- The environment it interacts with, together with its performance measure, actuators, and sensors, is specified by the [[Task Environment]].

[^1]: [Russell and Norvig, 2022, p. 54](zotero://open-pdf/library/items/JZXT5DZQ?page=54&annotation=CCQG9WPV)
