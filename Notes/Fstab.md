# Definition
> [!info] Fstab[^1]
> `/etc/fstab` is the plaintext file where Linux systems keep a permanent list of filesystems, their devices, and mount options, used to [[Mounting (Unix)|mount]] filesystems automatically at boot.

# Properties
- Newer alternatives include an `/etc/fstab.d` directory holding one configuration file per filesystem, and systemd mount units, which are often themselves generated from `/etc/fstab`.[^2]
