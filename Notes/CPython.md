# Definition
> [!info] CPython[^1]
> The standard, most widely used implementation of [[Python]], which compiles source code to [[Python Bytecode]] and executes it via the [[Python Virtual Machine|Python Virtual Machine (PVM)]].

# Properties
- Alternative Python implementations pursue their own specific goals and may or may not implement the full Python language defined by CPython, but come close enough to qualify as Pythons[^1].
