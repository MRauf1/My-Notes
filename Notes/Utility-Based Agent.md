# Definition
> [!info] Utility-Based Agent[^1]
> An [[Agent Program|agent program]] that chooses the action expected to maximize its [[Expected Utility|expected utility]], using an explicit [[Utility Function|utility function]] as an internalization of the [[Performance Measure|performance measure]].

# Properties
- Because "happy" does not sound scientific, economists and computer scientists use the term utility instead.
- Provided the internal utility function agrees with the external performance measure, an agent that maximizes utility is rational with respect to that performance measure.
- Not all utility-based agents are model-based: a [[Model-Free Agent|model-free agent]] can learn which action is best without ever learning how that action changes the environment.

[^1]: [Russell and Norvig, 2022, p. 72](zotero://open-pdf/library/items/JZXT5DZQ?page=72&annotation=GKX83AFW)
