# Definition

> [!info] Definition (Vector Image)[^1]
> A vector image is described by storing descriptions of shapes—areas of color bounded by lines or curves—with no reference to any particular pixel grid, i.e., it stores instructions for displaying the image rather than the pixels needed to display it.

# Properties
- Resolution independent, so it can be displayed well on very high-resolution devices.
- Must be rasterized into a [[Raster Image]] before it can be displayed.
- A type of [[Digital Image]].

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=68&annotation=6QKT4SFD)
