# Definition
> [!info] Causal Inference[^1]
> Inference about the effect of a treatment by comparing the observed outcome of each unit with that unit's unobserved outcome had it been exposed to the other treatment.

# Properties
- Each unit reveals only one outcome; the outcome under the treatment not received is a potentially observable [[Estimand]], so causal inference is a missing-data problem within [[Statistical Inference]].
- In a Bayesian treatment the unobserved outcomes are predicted from their posterior predictive distribution ([[Predictive Distribution]]).

[^1]: [Gelman et al., p. 4](zotero://open-pdf/library/items/HDF44SF4?page=14&annotation=V8QI2XES)
