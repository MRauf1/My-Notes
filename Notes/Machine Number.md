# Definition

> [!info] Definition 1 (Machine Number)[^1]
> A real number that is exactly representable in a given [[Floating-Point Number System]] is called a machine number.

If a real number $x$ is not a machine number, it must be approximated by a nearby floating-point number via [[Rounding]], denoted $fl(x)$.

[^1]: [Scientific Computing](zotero://open-pdf/library/items/EP5UUXW5?page=40)
