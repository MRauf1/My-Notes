# Definition

- For all $a, b$, $a < b$, $F(a) \leq F(b)$ ($F$ is non-decreasing)
- $\lim_{x \rightarrow - \infty} F(x) = 0$
- $\lim_{x \rightarrow \infty} F(x) = 1$
- $\lim_{x \rightarrow x_0+} F(x) = F(x_0)$ ($F$ is right-[[Continuous Function]])
- For $a < b$, $P(a \leq X \leq b) = F_X(b) - F_X(a)$
- $P(X = x) = F_X(x) - \lim_{z \rightarrow x^-} F_X(z)$
