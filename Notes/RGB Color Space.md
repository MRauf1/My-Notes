# Definition

> [!info] Definition (RGB Color Space)[^1]
> RGB color space displays a color by additively mixing three primary lights: one red, one green, and one blue.

# Properties
- Most computer graphics images are defined in terms of RGB color.
- Underlies [[24-bit Color]], where each of the three components is stored as an integer.
- Used as the pixel value type $V = (\mathbb{R}^+)^3$ in the [[Digital Image]] abstraction, and extended by a fourth [[Alpha Channel]] to form an RGBA image.

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=68&annotation=6QKT4SFD)
