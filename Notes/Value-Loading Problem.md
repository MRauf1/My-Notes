# Definition
> [!info] Value-Loading Problem[^1]
> The problem of instilling humanly meaningful values in an AI's motivation system. While the agent is unintelligent it may be unable to represent such values; once superintelligent, it may resist changes to its motivation system, having convergent instrumental reasons to do so.

# Types
Techniques:[^2]
- *Explicit representation* - coding a complete goal representation; for any plausible human value in a superintelligent sovereign, this appears hopelessly out of reach, as even approximating expected utility is AI-complete.
- *Evolutionary selection* - evolution produced human values once, but powerful search may find solutions satisfying the formal criteria but not implicit expectations, and risks [[Mind Crime]].
- *[[Reinforcement Learning|Reinforcement learning]]* - usable only if subordinated to a motivation system not organised around reward maximisation ([[Wireheading]]).
- *Associative value accretion* - mimicking how genes code for a goal-acquiring mechanism, so that humans acquire final values more complex than the genome from experience; but the AI might disable the accretion mechanism.
- *Motivational scaffolding* - an interim, simple final-goal system later replaced once the AI has richer representations; the AI may resist replacement due to goal-content integrity.
- *Value learning* - using the AI's intelligence to learn values picked out implicitly by a criterion; learning changes only the AI's beliefs about the goal, not the goal. The AI needs a criterion determining which percepts are evidence about the goal (e.g. "maximise the values described in a sealed letter"), and it then has instrumental reason to learn more rather than destroy what it may value. Challenges include interpreting descriptions as intended, installing motivation before the AI understands human concepts, and keeping its cognitive framework revisable. Variants include Yudkowsky's "causal validity semantics" (do what programmers were trying to say), the "Hail Mary" of deferring to hypothetical alien superintelligences' preferences, and Christiano's definition of a utility function via the simplest model (by a Kolmogorov-complexity measure) of a specific human's recorded input-output behaviour in an idealised environment.
- *Emulation modulation* - adjusting the motivations of emulations.
- *Institution design* - shaping the effective motivation of composite systems (like firms or states) through their internal organisation, e.g. rolling out each enhancement to a few emulated subagents first under review by unenhanced peers, so that capability grows in small verified steps and the hierarchy may stay stable even if each supervisory level is somewhat weaker than the one it supervises; risks include mind crime, unpredictable artificial subagents, sudden capability jumps, and tacit superintelligent coordination.

# Properties
- Once solved, a further problem remains: which values to load ([[Indirect Normativity]]).[^3]
- Implements [[Motivation Selection Methods]]; a formulation of the [[Value Alignment Problem]].
