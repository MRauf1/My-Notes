# Definition

> [!abstract] Theorem 1 ([[Linearly Independent]] [[Dimension]] [[Finite-Dimensional Vector Space]])[^1]
> If $V$ is [[Finite-Dimensional Vector Space]] and $(v_1, \dots, v_n)$ is a [[Linearly Independent]] list in $V$, then $dim(V) \geq n$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=185)
