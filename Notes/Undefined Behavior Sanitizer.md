# Definition
> [!info] Undefined Behavior Sanitizer[^1]
> A runtime checker provided by the LLVM project that can be enabled when compiling a program with a [[Compiler|compiler]] such as clang, to catch undefined behavior across various categories while the program runs.

# Properties
- Complements [[ThreadSanitizer]] as a runtime checking tool built into the [[Compiler|compiler]] toolchain.
