# Definition

> [!info] Definition 1 ([[Inverse Function|Invertible]] [[Linear Map]])[^1]
> [[Linear Map]] $T$ that has an [[Inverse Function]] $T^{-1}$.

> [!abstract] Theorem 2 (Using [[Coordinates]])[^2]
> Let $V, W$ be [[Finite-Dimensional Vector Space]] with [[Basis]] $\mathcal{B}_V, \mathcal{B}_W$ respectively. Suppose that $T \in \mathcal{L}(V, W)$ and let $A = [T]_{\mathcal{B}_V, \mathcal{B}_W}$. Then $A$ is invertible if and only if $T$ is invertible, and in that case, $[T^{-1}]_{\mathcal{B}_W, \mathcal{B}_V} = A^{-1}$.
