# Definition

> [!info] Definition 1 (Periodic [[Function]])[^1]
> [[Function]] $f$ is periodic if there exists $c \in \mathbb{R}$ such that
> $$
> \begin{align}
> f(t + c) = f(t)
> \end{align}
> $$
> for all $t \in \mathbb{R}$ where $t$ is in the function's [[Domain]].
> The smallest positive number $c$ for which this is true is called the [[Period]] of $f$.

# Properties
- If $\phi$ has period $p > 0$, then $\phi(x + np) = \phi(x)$ for all $x$ and all integers $n$; the sum of two functions of period $p$ has period $p$.[^2]
- $\int_a^{a+p} \phi(x)\, dx$ does not depend on $a$.[^2]
- A function given on an interval of length $p$ extends uniquely to a function of period $p$ ([[Periodic Extension]]); the full [[Fourier Series]] on $(-l, l)$ always sums to a $2l$-periodic function.[^3]
