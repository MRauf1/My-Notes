# Definition
> [!definition] Remote Procedure Call (RPC)[^1]
> Remote procedure call (RPC) is a system, residing in the lower part of the [[Application Layer|application layer]], that lets a program call a function on a remote program — identified by a program number — and receive back a result code or message, much as it would call a local function.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=268&annotation=VJAJTAAI)
