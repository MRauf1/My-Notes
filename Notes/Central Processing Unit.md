# Definition
> [!info] Central Processing Unit[^1]
> Also called processor. The active part of the computer, containing the datapath and control, which adds numbers, tests numbers, signals I/O devices to activate, and so on.

# Properties
- Combines the datapath and control components of the [[Five Classic Components of a Computer]].
- Executes [[Instruction|instructions]] and data fetched from [[Main Memory]].
- A single chip may contain multiple CPUs, called cores; see [[Multicore Microprocessor]].

[^1]: [Computer Organization and Design: The Hardware/Software Interface](zotero://open-pdf/library/items/YWPB5EDC?page=42&annotation=BQHJQU6M)
