# Definition
> [!definition] Group File[^1]
> `/etc/group` is the file that stores a Unix system's local group records, mapping [[Group (Unix)|group]] names to numeric GIDs and listing each group's explicit members.

# Properties
- Supports access control shared by several accounts at once, without assigning permissions to each account individually.[^1]

[^1]: [Linux Journey: User Management](https://labex.io/linuxjourney/courses/user-management)
