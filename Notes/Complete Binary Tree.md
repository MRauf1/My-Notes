# Definition

> [!info] Definition 1 (Complete [[Binary Tree]])[^1]
> [[Binary Tree]] where all [[Leaf Vertex]] are at the same [[Tree Height]].

Note: algorithms texts (e.g. Morin, for the [[Binary Heap]]) more commonly use "complete binary tree" for a *weaker* property — every level full except possibly the last, which is filled left to right — under which leaves need not all sit at the same height. See [[Complete Binary Tree (Data Structures and Algorithms)]] for that definition.

[^1]: [Building Blocks for Theoretical Computer Science](zotero://open-pdf/library/items/5IGT8C55?page=165)
