# Definition
> [!info] Partition Table[^1]
> A partition table is a small area of a disk that defines its [[Partition (Operating Systems)|partitions]].

# Types
- [[Master Boot Record]] (MBR) — the traditional partition table format.
- [[Globally Unique Identifier Partition Table (GPT)|GPT]] — a newer standard gaining traction.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=92&annotation=WBI2EHTV)
