# Definition
> [!definition] Linux Distribution[^1]
> A Linux distribution (distro) is a complete [[Operating System]] built around the [[Kernel (Operating System)|Linux kernel]], bundling it with system utilities, libraries, applications, and usually a package manager.

# Properties
- Many distros also include a [[Desktop Environment|desktop environment]] for graphical use.
- Bundles software from [[Upstream Project|upstream projects]] into [[Package (Software)|packages]], built and published through its own build infrastructure and [[Package Repository|repositories]].[^2]
