# Definition

> [!info] Definition 1 (Polish Space)
> A topological space is Polish if it is both:
> 1) [[Separable Metric Space|Separable]]: it contains a [[Countable Set|countable]] dense subset.
> 2) Completely metrizable: there exists SOME metric $d$ inducing its topology under which the space is a [[Complete Metric Space]] (the space need not already be complete under whatever metric it is given — only some compatible metric need be complete).

Being Polish is a *strictly stronger* condition than merely being [[Separable Metric Space|separable]] — separability alone says nothing about completeness. For instance, the open interval $(0, 1)$ with its usual metric is separable but not complete, yet it is still Polish: it is homeomorphic to $\mathbb{R}$ (which is complete), so a complete metric compatible with its topology exists even though the "obvious" one is not complete.

# Examples
- Every [[Complete Metric Space|complete]], [[Separable Metric Space|separable]] metric space is Polish (e.g. $\mathbb{R}^k$).
- Every [[Compact Metric Space|compact]] metric space is Polish, since compact metric spaces are both complete and separable.
