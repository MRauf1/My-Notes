# Definition
> [!info] Blob[^1]
> A blob is the [[Git Object]] type that stores a piece of file content, roughly analogous to a Unix inode's file contents; a blob holds no filename or other metadata of its own.

[^1]: [Pro Git](zotero://open-pdf/library/items/Y53JUJJW?page=423&annotation=XRTR3DCK)
