# Definition
> [!info] Loop Else Clause (Python)[^1]
> An optional clause on a [[While Loop (Python)|while]] or [[For Loop (Python)|for]] loop that runs if, and only if, the loop is exited normally — that is, without a `break` statement ending it early.

# Properties
- Unique to Python among mainstream languages; it gives explicit syntax for a common pattern — reacting to the "other," non-`break` way a loop can end — without manually setting and checking a flag variable to record whether the loop found what it was searching for[^2].
