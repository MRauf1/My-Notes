# Definition
> [!info] Import Alias (Python)[^1]
> The optional `as` clause on [[Import Statement (Python)|import]] or [[From Import Statement (Python)|from]], which binds an imported module or name to a different name in the importer's scope instead of its original name — e.g., `import modulename as name` or `from modulename import attrname as name`.

# Properties
- Commonly used to give a long or deeply nested dotted-path module a short nickname, to avoid a name collision with something already in use in the importer's scope, or to keep existing code working under a familiar name after a library renames or replaces one of its tools[^1].
