# Definition
> [!info] Computer Network (LAN and WAN)[^1]
> A local area network (LAN) is a network designed to carry data within a geographically confined area, typically within a single building. A wide area network (WAN) extends over hundreds of kilometers and can span a continent.

# Properties
- LANs are interconnected with switches that can also provide routing services and security.
- WANs cross continents and form the backbone of the Internet, which supports the web.
