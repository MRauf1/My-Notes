# Definition
> [!definition] Multitasking[^1]
> Multitasking is a system's capability to appear to run multiple processes simultaneously, even on a single-core CPU where only one process actually executes at any given moment.

# Properties
- Achieved through rapid [[Context Switch|context switching]] between processes, each running for a [[Time Slice]] too small for humans to perceive.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=27&annotation=NBSDE75L)
