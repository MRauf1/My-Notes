# Definition

> [!info] Definition 1 (Unit Tangent [[Vector Field on Curve]])[^1]
> Let $\beta: I \rightarrow \mathbb{R}^3$ be a [[Unit Speed Curve]]. Then $T(s) = \beta'(s)$ is the unit tangent [[Vector Field on Curve]] $\beta$.

$T = \beta'$ is a genuine equality, not just a resemblance: a [[Vector Field on Curve]] is itself defined as a vector-valued function of the parameter $s$, which is exactly what $\beta'$ is, so $T$ is defined to be $\beta'$ rather than merely related to it.
