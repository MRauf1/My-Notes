# Definition
> [!info] Tabular Data[^1]
> Data in which each input is a fixed-length vector $\mathbf{x} \in \mathbb{R}^{D}$ of values characterizing the example, with no internal structure: if the order of the input entries is changed and a new model is built, the model's prediction is expected to remain the same.

# Properties
- Lacking internal structure, it contrasts with structured inputs such as images or text, whose entries carry spatial or sequential relationships.
- Commonly the input to [[Regression]] and [[Classification]] problems in [[Supervised Learning]]; a collection of such vectors is organized as a [[Data Matrix]].
