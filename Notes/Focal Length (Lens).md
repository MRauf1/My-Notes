# Definition
> [!info] Definition (Focal Length (Lens))[^1]
> For a [[Lens]], the characteristic distance $f$, given by the [[Lensmaker's Equation]], at which parallel rays entering the lens converge to (or appear to diverge from) a single point.

# Properties
- Positive for a [[Convex Lens]], which converges parallel rays to a real focus; negative for a [[Concave Lens]], which causes parallel rays to diverge as if from a virtual focus.
- Used to define a camera's [[F-Number]], $N = f/A$, and its [[Depth of Field]].
- Distinguished from the computer graphics [[Focal Length]] notion, which specifies an image plane distance chosen as a parameter of a virtual camera model, rather than a property derived from a physical lens's curvature and index of refraction.

[^1]: [MIT Vision Book - Lenses](https://visionbook.mit.edu/lenses.html)
