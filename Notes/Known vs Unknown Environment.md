# Definition
> [!info] Known vs. Unknown Environment[^1]
> A dimension referring not to the environment itself but to an agent's (or designer's) state of knowledge about the "laws of physics" of the environment. In a known environment, the outcomes (or outcome probabilities, if nondeterministic) for all actions are given; in an unknown environment, the agent must learn how the environment works in order to make good decisions.

# Properties
- Independent of [[Observability (Task Environment)|observability]]: a known environment can be partially observable, and an unknown environment can be fully observable.

[^1]: [Russell and Norvig, 2022, p. 64](zotero://open-pdf/library/items/JZXT5DZQ?page=64&annotation=XESZWJ5D)
