# Definition
> [!info] Critic[^1]
> The component of a [[Learning Agent|learning agent]] that tells the learning element how well the agent is doing with respect to a fixed performance standard.

# Properties
- Necessary because percepts themselves provide no indication of the agent's success.
- The performance standard must be conceptually fixed and external to the agent, since the agent must not be able to modify it to fit its own behavior.
- Distinguishes part of the incoming percept as a [[Reward (Artificial Intelligence)|reward]] or penalty, providing direct feedback on the quality of the agent's behavior.
