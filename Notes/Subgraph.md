# Definition

> [!info] Definition 1 (Sub [[Graph]])[^1]
> If $G, G'$ are [[Graph]], then $G'$ is a subgraph of $G$ if and only if $V' \subseteq V$ and $E' \subseteq E$.

[^1]: [Building Blocks for Theoretical Computer Science](zotero://open-pdf/library/items/5IGT8C55?page=121)
