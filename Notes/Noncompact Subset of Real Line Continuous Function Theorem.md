# Definition

> [!abstract] Theorem 1 (Noncompact Subset of Real Line [[Continuous Function]] Theorem)[^1]
> Let $E \subseteq \mathbb{R}$ be a set that is not [[Compact Set|compact]]. Then
> 1) there exists a [[Continuous Function]] on $E$ which is not [[Bounded Function|bounded]];
> 2) there exists a continuous and bounded function on $E$ which has no [[Maximum]].
>
> If, in addition, $E$ is [[Bounded Set|bounded]], then
> 3) there exists a continuous function on $E$ which is not [[Uniformly Continuous Function|uniformly continuous]].

Compactness is essential (not merely convenient) in the [[Continuous Function Compact Metric Space Theorem]], the [[Extreme Value Theorem]], and the [[Continuous to Uniformly Continuous Theorem]]: on $\mathbb{R}$, each of these conclusions holding for every continuous function on $E$ characterizes compactness of $E$.

# Properties
- Converse of [[Continuous Function Compact Metric Space Theorem]], [[Extreme Value Theorem]], and [[Continuous to Uniformly Continuous Theorem]] for subsets of $\mathbb{R}$ (via the [[Heine-Borel Theorem]]).
