# Definition
> [!info] Agent Program and Architecture[^1]
> $$
> \text{agent} = \text{architecture} + \text{program}
> $$
> The agent program is the software that implements an [[Agent Function|agent function]], the mapping from percepts to actions. It runs on a computing device with physical sensors and actuators, called the agent architecture.
