# Definition
> [!info] Episodic Task[^1]
> A task in which the environment deterministically transitions into an [[Absorbing State]] after a fixed number of time steps, corresponding to the notion of termination.

# Properties
- A [[Finite-Horizon Markov Decision Process]] constructed via state-space augmentation is an example of an episodic task.

[^1]: [Jiang, MDP Preliminaries (CS 542 notes), p. 5](https://nanjiang.cs.illinois.edu/files/cs542f22/note1.pdf#page=5)
