# Definition
> [!info] Single-Agent vs. Multiagent Environment[^1]
> A dimension of a [[Task Environment|task environment]] describing whether one or several agents operate within it. An entity counts as a second agent, rather than a mere object obeying the laws of physics, when its behavior is best described as maximizing a performance measure whose value depends on the first agent's behavior.

# Types
- Competitive - an agent's performance measure is maximized precisely when another agent's performance measure is minimized.
- Cooperative - agents' performance measures are aligned, at least partially, such as when avoiding collisions benefits every agent.

# Properties
- A multiagent environment can be simultaneously partially cooperative and partially competitive.
