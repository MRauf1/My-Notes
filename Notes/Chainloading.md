# Definition
> [!info] Chainloading[^1]
> Chainloading is [[GRUB]] loading and running a separate boot loader installed on a specific disk partition — used, for example, to keep an MBR-style boot loader usable on a UEFI system.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=132&annotation=SN2DAKNB)
