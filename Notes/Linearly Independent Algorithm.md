# Definition

> [!abstract] Theorem 1 ([[Linearly Independent]] [[Algorithm]])[^1]
> To check whether list of [[Vector]] $(v_1, \dots, v_n)$ in $\mathbb{F}^m$ is [[Linearly Independent]]:
> 1) Put the [[Matrix]] in [[Row Echelon Form]].
> 2) It is [[Linearly Independent]] if and only if there is a [[Pivot Variable]] in every column of the [[Row Echelon Form]].
