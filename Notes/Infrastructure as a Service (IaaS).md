# Definition
> [!definition] Infrastructure as a Service (IaaS)[^1]
> Infrastructure as a service (IaaS) is a form of [[Cloud Computing]] that lets a user provision and control basic computing resources — CPU, memory, storage, and networking — on a remote server.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=373&annotation=JPZ7RX4C)
