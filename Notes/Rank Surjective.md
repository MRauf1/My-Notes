# Definition

> [!abstract] Theorem 1 ([[Rank]] [[Surjective Function]])[^1]
> If $T \in \mathcal{L}(V, W)$ and $dim(W) < \infty$, then $T$ is [[Surjective Function]] if and only if $rank(T) = dim(W)$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=193)
