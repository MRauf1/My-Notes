# Definition

> [!abstract] Theorem 1 ([[Similar Matrix]] [[Eigenvalue]])[^1]
> [[Similar Matrix]] have the same [[Eigenvalue]].

In fact, [[Similar Matrix Characteristic Polynomial|similar matrices share the same characteristic polynomial]], so their eigenvalues match not just as a set but with the same [[Algebraic Multiplicity of Eigenvalue|multiplicities]].
