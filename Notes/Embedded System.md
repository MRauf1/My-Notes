# Definition
> [!definition] Embedded System[^1]
> An embedded system is anything designed to serve one specific purpose, such as a music player, video streamer, or thermostat, as opposed to a desktop or server system that handles many different kinds of tasks, but perhaps none of them exceptionally well.

# Properties
- Almost the opposite of distributed computing: rather than expanding an operating system's scale, an embedded system usually (though not always) shrinks it, often into a small device.[^2]
- Often combines specialized hardware with software; buying a smaller, dedicated device with only the necessary hardware and none of the unnecessary hardware is usually preferable.[^3]
- Growing interest is driven by more capable small hardware, particularly [[System-on-a-Chip (SoC)|system-on-a-chip]] designs.[^4]
