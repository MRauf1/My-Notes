# Definition
> [!definition] Bash[^1]
> Bash (the "Bourne-again" shell) is Linux's enhanced version of the [[Bourne Shell]], and is the default shell on most Linux distributions.

# Properties
- On a Linux system, /bin/sh is normally a link to bash.
