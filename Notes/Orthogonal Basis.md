# Definition

> [!info] Definition 1 ([[Orthogonal Vector]] [[Basis]])[^1]
> If $\mathcal{B} = (e_1, \dots, e_n)$ is an [[Orthogonal Vector]] list which is also a [[Basis]] for $V$, then $\mathcal{B}$ is an orthogonal basis for $V$.
