# Definition
> [!info] Yield Statement (Python)[^1]
> Suspends a [[Generator (Python)|generator]] function and sends a value back to its caller, while retaining enough state for the function to resume immediately after that point the next time a value is requested.

# Properties
- Unlike [[Return Statement (Python)|return]], which ends a function's call entirely, `yield` pauses it in place, preserving local variables and the current code location for the next resumption.
