# Definition
> [!definition] Domain Name System (DNS)[^1]
> DNS (Domain Name Service) is the system that maps human-readable names, such as `www.example.com`, to numeric [[IP Address|IP addresses]].

# Properties
- Exists because IP addresses are difficult to remember and subject to change.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=222&annotation=GMZDYII6)
