# Definition
> [!info] Tipitaka[^1]
> The "three baskets": the three-section collected work in which the Buddha's original teachings are preserved; the canon of [[Theravada Buddhism]].

# Types
- **Vinaya** — the code of discipline for monks, nuns, and lay people.[^1]
- **Suttas** — public discourses attributed to the Buddha (e.g., the *Satipatthana Sutta*, the source of [[Vipassana Meditation]]).[^1]
- **Abhidhamma** — a set of deep psycho-philosophical teachings (e.g., the [[Universal Mental Factors]]).[^1]

[^1]: [Gunaratana, p. 3](zotero://open-pdf/library/items/AUJ2ZCA3?page=3&annotation=ML2NI7SQ)
