# Definition
> [!info] Definition (Color Gamut)[^1]
> The range of colors that can be produced by non-negative combinations of a given set of primary lights.

# Properties
- Limits which colors a [[Color Reproduction System]] can actually reproduce, even when its sensing and mixing matrices otherwise satisfy the conditions for perfect color reproduction.
- The [[CIE XYZ Color Space|CIE color-matching functions]] are all-positive, but no set of physically realizable primary lights forms a color-matching system with them, illustrating that gamut and color-matching-function positivity are separate constraints.

[^1]: [MIT Vision Book - Color](https://visionbook.mit.edu/color.html)
