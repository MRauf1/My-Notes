# Definition
> [!info] Assembly Language[^1]
> A symbolic representation of machine [[Instruction|instructions]], translated into [[Machine Language]] by an [[Assembler]].

# Properties
- Requires the programmer to write one line for every instruction the computer will follow, forcing the programmer to think like the computer.
- Produced from a [[High-Level Programming Language]] (the source language) by a [[Compiler]].
- Programmed directly, rather than in an available high-level language, primarily when a program's speed or size is critically important; the trade-off is that assembly programs are longer and harder to write, read, and verify than equivalent high-level-language code, which is why even reliability-critical embedded software is often still written in a high-level language despite the performance cost.
