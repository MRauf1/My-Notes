# Definition
> [!info] Definition (Tristimulus Values)[^1]
> The amounts of each of three primary colors required to match a given color, serving as a set of coordinates for that color.

# Properties
- Well-defined as color coordinates because of [[Grassmann's Laws|the transitivity and linearity of color matches]], guaranteed by the [[Trichromatic Theory of Color Vision]].
- Geometrically, measuring the tristimulus values of a color amounts to finding the projection of its light spectrum onto the 3D subspace spanned by a set of color-matching functions, which need not be the eye's own cone sensitivity curves, only some linear combination of them.
- The [[CIE XYZ Color Space]] defines a standard set of tristimulus values, $X$, $Y$, and $Z$.

[^1]: [MIT Vision Book - Color](https://visionbook.mit.edu/color.html)
