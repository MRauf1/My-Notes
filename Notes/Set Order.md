# Definition

> [!info] Definition 1 ([[Set]] Order)[^1]
> Let $S$ be a [[Set]]. An order on $S$ is a [[Relation]] denoted by $<$, with the properties
> 1) If $x, y \in S$, then only one of the following is true:
> 	1) $x < y$
> 	2) $x = y$
> 	3) $y < x$
> 2) If $x, y, z \in S$ and $x < y, y < z$, then $x < z$
