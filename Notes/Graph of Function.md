# Definition

> [!info] Graph of Function[^1]
> The graph of a [[Function|function]] $f: X \to Y$ is the [[Set|set]]
> $$
> \begin{align}
> \operatorname{graph}(f) = \{(x, f(x)) : x \in X\} \subseteq X \times Y
> \end{align}
> $$
> For a real function of one variable, it is the set of [[Point|points]] $(x, y)$ in the plane that satisfy $y = f(x)$.

More generally, the graph of an [[Equation|equation]] in $x$ and $y$ is the set of points $(x, y)$ that satisfy it. Not to be confused with a [[Graph]] in the graph-theory sense.

# Properties
- A set of [[Ordered Pair|ordered pairs]] $G \subseteq X \times Y$ is the graph of a function $\iff$ each $x \in X$ appears in exactly one pair of $G$. For real functions, this is the [[Vertical Line Test]].
- [[Function Transformation|Function transformations]] act geometrically on the graph: [[Vertical Shift|vertical]] and [[Horizontal Shift|horizontal shifts]], [[Reflection|reflections]], and [[Horizontal Scaling|scalings]].
