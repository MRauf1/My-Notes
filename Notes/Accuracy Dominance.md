# Definition
> [!info] Accuracy Dominance[^1]
> A set of beliefs $ dominates a set of beliefs $ if and only if $ is more accurate than $ in every possibility, i.e., for inaccuracy measure $,
> 825810
> \begin{align}
> I(B_1, w) < I(B_2, w) \quad \text{for every possible world } w
> \end{align}
> 825810
> A set of beliefs is dominated if and only if some other set of beliefs dominates it.

# Properties
- Used in the [[Accuracy Argument]] through the [[Accuracy Theorem]] and [[Converse Accuracy Theorem]].
