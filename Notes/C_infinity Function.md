# Definition

> [!info] Definition 1 ($C^{\infty}$ [[Function]])[^1]
> [[Real-Valued Function]] $f: U \rightarrow \mathbb{R}$ is $C^{\infty}$ at $p$ if it is $C^k$ for all $k \geq 0$ at $p$.
> Similar definition holds for when $f$ is [[Real Vector-Valued Function]] with the only addition being that the component [[Function]] $f^1, \dots, f^m$ are individually $C^{infty}$.

Also known as smooth or infinitely differentiable.

# Properties
- $f$ that is $C^{\infty}$ is [[Bijective Function]], then its [[Inverse Function]] is not necessarily $C^{\infty}$ (but it is for [[Complex Number]] domain/[[Holomorphic Function]])
