# Definition
> [!info] Wavefront[^1]
> At a fixed time, a wavefront is a set of points where the wave has the same [[Phase (Waves)|phase]]: a level set $\{\mathbf{x} : \theta(\mathbf{x}, t) = \text{const}\}$. It is a surface in 3D, a curve in 2D. Wavefronts are usually drawn at the [[Crest and Trough|crests]], one [[Wavelength|wavelength]] apart.

# Properties
- **Shape by type of wave**: parallel planes for a [[Plane Wave]], concentric spheres for a point source.
- **Rays.** In an isotropic medium, the direction of propagation (a *ray*) is perpendicular to the wavefronts, along $\nabla\theta$, i.e. along the [[Wave Vector|wave vector]].
- Wavefronts advance at the [[Phase Velocity|phase velocity]].
- **The "wavefront" of the wave equation**, the leading edge of a disturbance, is a related but different usage ([[Huygens's Principle]]).
