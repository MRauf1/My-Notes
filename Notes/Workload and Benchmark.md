# Definition
> [!info] Workload and Benchmark[^1]
> A workload is a set of programs run on a computer, either the actual collection of applications run by a user or a mix of real programs constructed to approximate such a collection; a typical workload specifies both the programs and their relative frequencies. A benchmark is a program selected for use in comparing computer performance.

# Properties
- Used to obtain the [[Response Time and Throughput|execution time]] measurements that feed the [[CPU Performance Equation]] when evaluating or comparing real computers.
