# Definition
> [!info] Bare Repository[^1]
> A bare repository is a [[Git]] repository consisting only of the contents of a project's Git directory, with no checked-out working directory alongside it.

# Properties
- Since a [[Remote Repository (Git)|remote repository]] is used only as a collaboration point rather than a place to edit files, there is no need for it to have a snapshot checked out on disk, so it is generally kept bare.
