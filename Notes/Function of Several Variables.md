# Definition

> [!info] Definition 1 (Function of Two Variables)[^1]
> A function $f$ of two variables is a rule that assigns to each ordered pair $(x, y)$ in a set $D \subseteq \mathbb{R}^2$ (the [[Domain]]) a unique real number $f(x, y)$. The [[Range]] is $\{f(x, y) \mid (x, y) \in D\}$, and the graph is the surface $\{(x, y, z) \mid z = f(x, y),\ (x, y) \in D\}$. Functions of $n$ variables $f: D \subseteq \mathbb{R}^n \to \mathbb{R}$ are defined the same way.

# Properties
- A [[Real-Valued Function]] on a subset of $\mathbb{R}^n$. The implied domain is the largest set where the formula is defined.
- Visualized by [[Level Set|level curves]] (or level surfaces for three variables).
- Graphs transform as in one variable ([[Function Transformation]]): $f + c$ shifts vertically, $f(x - a, y - b)$ shifts horizontally, $-f$ reflects.
- Calculus on them: [[Limit of Function of Several Variables]], [[Partial Derivative]].
