# Definition

> [!abstract] Theorem 1 ([[Uniformly Continuous Function]] [[Function Composition|Composition]])[^1]
> Let $X, Y, Z$ be [[Metric Space|metric spaces]], $f: X \rightarrow Y$ uniformly continuous on $X$, and $g: Y \rightarrow Z$ uniformly continuous on $f(X)$. Then $g \circ f: X \rightarrow Z$ is uniformly continuous on $X$.

# Properties
- Uniform analogue of [[Continuous Function Composition]].

[^1]: [Principles of Mathematical Analysis](zotero://open-pdf/library/items/3BD27IHF?page=108)
