# Definition

> [!info] Definition 1 (Linearly Dependent)[^1]
> List of [[Vector]] $(v_1, \dots, v_n)$ in $V$ (with $n \geq 2$) is linearly dependent if for some $i$, $v_i$ is a [[Linear Combination]] of $\{v_j | j \neq i\}$.
> A single [[Vector]] is linearly dependent if and only if $v = 0$.

> [!info] Definition 2 (Second Definition)[^1]
> List of [[Vector]] $(v_1, \dots, v_n)$ in $V$ is linearly dependent if there exist scalars $a_1, \dots, a_n \in \mathbb{F}$ which are not all $0$ such that
> $$
> \begin{align}
> \sum_{j=1}^n a_j v_j = 0
> \end{align}
> $$
