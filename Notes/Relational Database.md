# Definition
> [!definition] Relational Database[^1]
> A relational database (Relational Database Management System, RDBMS) is a general-purpose [[Database (Computing)|database]] that excels at tying separate sets of data together, such as quickly cross-referencing two tables that share a common field.

# Properties
- Normally accessed using SQL (Structured Query Language).[^1]
