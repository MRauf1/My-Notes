# Definition

> [!abstract] Theorem 1 ([[Rank]]-[[Nullity]] Theorem)[^1]
> If $A \in M_{m, n}(\mathbb{F})$, then $rank(A) + null(A) = n$.
> If $T \in \mathcal{L}(V, W)$, then $rank(T) + null(T) = dim(V)$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=195)
