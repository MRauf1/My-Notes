# Definition
> [!abstract] Theorem 1 ([[Similar Matrix]] [[Characteristic Polynomial]] is an Invariant)[^1]
> If $A, B \in M_n(\mathbb{F})$ are similar, then $p_A(x) = p_B(x)$.

Since the characteristic polynomial of a matrix is a [[Invariant of Matrix|matrix invariant]], it follows that not only the [[Similar Matrix Eigenvalue|eigenvalues of a matrix]] but also their [[Algebraic Multiplicity of Eigenvalue|multiplicities]] are invariants: similar matrices have the same eigenvalues, with the same multiplicities.
