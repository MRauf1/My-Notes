# Definition

> [!info] Definition 1 (Level Curves and Level Surfaces)[^1]
> The level curves of $f(x, y)$ are the curves $f(x, y) = k$ for constants $k$ in the [[Range]] of $f$. For $f(x, y, z)$, the level surfaces are $f(x, y, z) = k$. In general, the level set of $f: \mathbb{R}^n \to \mathbb{R}$ at $k$ is $\{x \mid f(x) = k\}$.

# Properties
- A contour map displays several level curves; their spacing shows steepness.
- The [[Gradient Vector]] $\nabla f$ is orthogonal to the level set through each point (when $\nabla f \neq 0$), which gives the [[Tangent Plane (Calculus)|tangent plane]] to a level surface.
- Example: the level surfaces of $x^2 + 3y^2 + 5z^2$ are ellipsoids ([[Ellipse]]).
- See [[Function of Several Variables]].
