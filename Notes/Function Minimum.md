# Definition

> [!info] Definition 1 ([[Function]] [[Minimum]])
> For a [[Function|function]] $f$, the value $b$ is the minimum $\iff$ $b = f(x_0)$ for some $x_0$ in the [[Domain|domain]] of $f$ and $b \leq f(x)$ $\forall x$ in the domain of $f$.[^1]
