# Definition

> [!abstract] Theorem 1 ([[Graph Euler Circuit]] Existence Theorem)[^1]
> [[Graph Euler Circuit]] exists if and only if the [[Graph]] $G$ is a [[Connected Graph]] and each [[Vertex]] has [[Degree of Vertex]] that is [[Even Number]].

[^1]: [Building Blocks for Theoretical Computer Science](zotero://open-pdf/library/items/5IGT8C55?page=125)
