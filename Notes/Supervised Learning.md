# Definition

[[Subset|Subset]] of [[Machine Learning|machine learning]] that maps inputs to outputs using labeled data.[^1]

# Properties
- Equivalently characterized as observing example input-output behavior and inferring a functional mapping that explains it, in contrast to [[Unsupervised Learning]] and [[Reinforcement Learning]], which optimize for desirable properties of the mapping without being given such examples.[^2]
- Learning proceeds in a [[Training Phase]], which searches for a well-performing mapping on training data, followed by a [[Testing Phase]], which deploys that mapping on new instances.
