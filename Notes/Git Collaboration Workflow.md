# Definition
> [!info] Git Collaboration Workflow[^1]
> A Git collaboration workflow is a pattern for how multiple developers coordinate and integrate their contributions to a shared project history, made possible by [[Git]]'s [[Distributed Version Control System|distributed]] model.
