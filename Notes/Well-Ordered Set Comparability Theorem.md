# Definition
> [!abstract] Well-Ordered Set Comparability Theorem[^1]
> If $X$ and $Y$ are [[Well-Ordered Set|well ordered sets]], then exactly one of the following holds up to [[Order Isomorphism|order isomorphism]]:
> - $X$ is order isomorphic to $Y$,
> - $X$ is order isomorphic to an [[Initial Segment]] in $Y$,
> - $Y$ is order isomorphic to an initial segment in $X$.

Well-ordered sets are therefore linearly ordered by "length", which is the idea behind ordinal numbers.

# Properties
- Combined with the [[Well Ordering Principle (Set Theory)|well ordering principle]], it shows any two cardinalities are comparable: $\operatorname{card}(X) \leq \operatorname{card}(Y)$ or $\operatorname{card}(Y) \leq \operatorname{card}(X)$ (see [[Set Cardinality]]).
- Used to prove uniqueness of the [[Set of Countable Ordinals]].
