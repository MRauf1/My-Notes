# Definition

> [!info] Definition 1 (Symmetric [[Relation]])[^1]
> Let $R: A \rightarrow A$ be a [[Relation]]. It is symmetric if for all $x, y \in A$, $(x, y) \in R \implies (y, x) \in R$.
> $R$ is symmetric if and only if $R = R^{-1}$.

# Types
- [[Symmetric Closure]]

# Properties
- If $R$ is symmetric, so is $R^{-1}$
- If $R_1, R_2$ are symmetric, then so is $R_1 \cup R_2$, $R_1 \cap R_2$, $R_1 \setminus R_2$, $R_1 \circ R_2$ (if and only if $R_1 \circ R_2 = R_2 \circ R_1$)

[^1]: [HOW TO PROVE IT: A Structured Approach, Second Edition](zotero://open-pdf/library/items/THI2Q4PN?page=198)
