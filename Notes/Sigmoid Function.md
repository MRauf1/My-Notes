# Definition

> [!info] Definition 1 (Sigmoid [[Function]])
> Any [[Function]] whose graph is S-shaped (whose graph is a sigmoid curve).

# Types
- [[Logistic Function]]

# Properties
- In deep learning, "sigmoid" usually means the logistic sigmoid ([[Standard Logistic Function]]) $\mathrm{sig}[z] = \frac{1}{1 + \exp[-z]}$, which maps $\mathbb{R}$ to $(0, 1)$ and is used to produce the Bernoulli parameter in the [[Binary Cross-Entropy Loss]].[^1]
