# Definition
> [!info] Policy
> In a [[Markov Decision Process]], a decision-making strategy $\pi$ by which an agent chooses actions adaptively based on the current state. The agent's goal is to choose a policy $\pi$ to maximize the expected [[Discounted Return]], $V^\pi_M(s_1)$.

# Types
- [[Deterministic Policy]]
- [[Stochastic Policy]]
- [[Optimal Policy]]
- [[Greedy Policy]]

# Properties
- Induces the randomness (jointly with the [[Transition Function]]) in a [[Trajectory]] generated by following $\pi$.
- The [[Value Function]] $V^\pi_M$ and [[Action-Value Function]] $Q^\pi_M$ are defined with respect to a fixed policy $\pi$.
