# Definition

> [!info] Definition 1 (k-Cell)[^1]
> Let $k$ be a positive integer and $a_i < b_i$ for $i = 1, \dots, k$. The set of all points $\mathbf{x} = (x_1, \dots, x_k) \in \mathbb{R}^k$ whose coordinates satisfy $a_i \leq x_i \leq b_i$ for $1 \leq i \leq k$ is called a $k$-cell.

A $1$-cell is a closed [[Interval Notation|interval]]; a $2$-cell is a (closed) rectangle.

# Properties
- Every $k$-cell is [[Convex Set|convex]].
- Every $k$-cell is [[Compact Set|compact]].

[^1]: [Principles of Mathematical Analysis](zotero://open-pdf/library/items/3BD27IHF?page=40)
