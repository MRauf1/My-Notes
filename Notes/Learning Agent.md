# Definition
> [!info] Learning Agent[^1]
> An [[Agent Program|agent program]] divided into four conceptual components: a performance element, which takes in percepts and decides on actions; a learning element, responsible for making improvements to the performance element; a [[Critic]], which evaluates the agent against a fixed performance standard; and a [[Problem Generator|problem generator]], which suggests exploratory actions.

# Properties
- The learning element uses feedback from the critic on how the agent is doing to determine how the performance element should be modified to do better in the future.
