# Definition
> [!info] Computable Function[^1]
> A function on the integers is computable if it can be computed by an effective procedure (an algorithm) that halts after finitely many steps.

# Properties
- [[Gödel's Incompleteness Theorem|Gödel's incompleteness theorem]] implies that some functions on the integers are not computable.
- Alan Turing characterized exactly which functions are computable; see [[On Computable Numbers (Turing)]].
- Distinguished from [[Tractability]], which concerns the efficiency, rather than the possibility, of computation.

[^1]: [Russell and Norvig, 2022, p. 27](zotero://open-pdf/library/items/JZXT5DZQ?page=27&annotation=FZ94P7DI)
