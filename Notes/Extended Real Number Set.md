# Definition

> [!info] Definition 1 (Extended [[Set of Real Numbers]])[^1]
> [[Set of Real Numbers]] [[Set Union]] $\{-\infty, \infty\}$ whereby for all $x \in \mathbb{R}$, $-\infty < x < \infty$.

[^1]: [Principles of Mathematical Analysis](zotero://open-pdf/library/items/3BD27IHF?page=20)
