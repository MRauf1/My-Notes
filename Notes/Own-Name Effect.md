# Definition
> [!info] Own-Name Effect[^1]
> One's own name is a uniquely salient stimulus. It captures attention even when unattended. In the cocktail-party effect, about a third of listeners noticed their own name in an ignored channel (Moray, 1959). Carnegie's Principle 3: "Remember that a person's name is to that person the sweetest and most important sound in any language."

# Properties
- **Evidence.**
	- Hearing one's own name activates self-referential brain regions more than other names (Carmody and Lewis, 2006).
	- Using a person's name in a request increased compliance in field experiments (Howard, Gengler and Jain, 1995).
	- The *name-letter effect*: people prefer the letters in their own name (Nuttin, 1985).
- **Remembering names.** Carnegie says people forget names because they don't make the effort, and he describes Napoleon's routine.[^2] The routine combines several supported techniques:
	- Ask for the name and its spelling. Hearing it clearly and spelling it supports encoding.
	- Repeat it during the conversation. Spaced retrieval of new names, with gradually lengthening gaps, improved recall (Landauer and Bjork, 1978). See [[Spaced Repetition]].
	- Associate the name with the person's features. This is elaborative encoding, and the face–name mnemonic improves name recall (Morris, Jones and Hampson, 1978).
	- Write it down later. Writing adds visual encoding and a further retrieval attempt.[^3]
