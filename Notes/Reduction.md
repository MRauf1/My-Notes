# Definition
> [!info] Reduction[^1]
> Reducing a problem $X$ to a problem $Y$ means writing an [[Algorithm]] for $X$ that uses an algorithm for $Y$ as a black box (subroutine). The correctness of the algorithm for $X$ may not depend in any way on *how* the algorithm for $Y$ works; the only assumption allowed is that the black box solves $Y$ correctly.

Reduction is the single most common technique in algorithm design.[^1]
