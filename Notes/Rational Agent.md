# Definition
> [!info] Rational Agent[^1]
> An agent that acts so as to achieve the best outcome or, when there is uncertainty, the best expected outcome.

More precisely: for each possible percept sequence, a rational [[Agent|agent]] should select an action that is expected to maximize its [[Performance Measure|performance measure]], given the evidence provided by the percept sequence and whatever built-in knowledge the agent has.[^2]

# Properties
- Acting rationally does not necessarily require inference or deliberation; a reflex action, such as recoiling from a hot stove, is often more successful than a slower action taken after careful deliberation.
- All the skills needed to pass the [[Turing Test]] also allow an agent to act rationally.
- The rational-agent formulation has prevailed throughout most of the history of [[Artificial Intelligence]], giving rise to the [[Standard Model of Artificial Intelligence|standard model]].
- What is rational at any given time depends on four things: the performance measure defining the criterion of success, the agent's prior knowledge of the environment, the actions the agent can perform, and the agent's [[Percept|percept sequence]] to date.[^2]
