# Definition
> [!info] Task Environment[^1]
> A specification of the [[Performance Measure|performance measure]], the external environment, the actuators, and the sensors for a given [[Agent|agent]] — commonly abbreviated PEAS. Specifying the task environment is always the first step in designing an agent.

# Properties
- Task environments vary along several dimensions: [[Observability (Task Environment)|observability]], [[Multiagent Environment|number of agents]], [[Determinism (Task Environment)|determinism]], [[Episodic vs Sequential Environment|episodicity]], [[Environment Dynamics|dynamics]], [[Discrete vs Continuous Environment|discreteness]], and [[Known vs Unknown Environment|whether it is known]].
- The hardest case is a task environment that is partially observable, multiagent, nondeterministic, sequential, dynamic, continuous, and unknown.

[^1]: [Russell and Norvig, 2022, p. 78](zotero://open-pdf/library/items/JZXT5DZQ?page=78&annotation=EDLA7Z4Q)
