# Definition
> [!info] Loadable Kernel Module[^1]
> A loadable kernel module is a [[Kernel (Operating System)|kernel]] component that is not built into the main kernel image but can instead be loaded on demand.

# Properties
- Some devices needed during boot may require their modules to be loaded before the true root filesystem is mounted, typically supplied through the [[Initial RAM Filesystem (Initrd)|initial RAM filesystem]].
