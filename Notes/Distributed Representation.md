# Definition
> [!info] Localist vs. Distributed Representation[^1]
> An axis describing how concepts are mapped to locations in physical memory (in a computer or a brain). A localist representation maps each concept one-to-one to a single memory location; a distributed representation spreads the representation of a concept over many memory locations, each of which is also shared by the representations of other concepts.

# Properties
- Distributed representations are more robust against noise and information loss: garbling a few bits moves a concept to a nearby point in a multidimensional representation space, which has similar meaning, whereas a localist representation can be confused with an arbitrary, unrelated concept by the same corruption.

[^1]: [Russell and Norvig, 2022, p. 77](zotero://open-pdf/library/items/JZXT5DZQ?page=77&annotation=6RQNDG3A)
