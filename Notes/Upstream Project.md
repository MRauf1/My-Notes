# Definition
> [!definition] Upstream Project[^1]
> An upstream project is the party that develops and releases a piece of software's original source code, distinct from the [[Linux Distribution|Linux distribution]] maintainers who adapt selected releases for their distribution.

# Properties
- Distribution maintainer work can include reviewing licenses, applying integration or security patches, defining build instructions, splitting output into packages, declaring dependencies, running tests, and maintaining updates.[^1]
- Responsibilities vary: some upstream projects publish their own packages, while distributions may build independently from source instead.[^1]

[^1]: [Linux Journey: Packages](https://labex.io/linuxjourney/courses/packages)
