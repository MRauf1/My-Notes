# Definition

> [!info] Definition 1 (Simple Discontinuity)[^1]
> Let $f$ be defined on $(a, b)$. If $f$ is discontinuous at a point $x$ ([[Discontinuity]]), and if both [[One-Sided Limit of Function|one-sided limits]] $f(x^+)$ and $f(x^-)$ exist, then $f$ has a discontinuity of the first kind, or a simple discontinuity, at $x$.

# Types
There are two ways in which a function can have a simple discontinuity:[^1]
- $f(x^+) \neq f(x^-)$, in which case the value $f(x)$ is immaterial: [[Jump Discontinuity]].
- $f(x^+) = f(x^-) \neq f(x)$: removable discontinuity.

# Properties
- For any real function $f$ on $(a, b)$, the set of points at which $f$ has a simple discontinuity is at most [[Countable Set|countable]].[^2]
- Every discontinuity of a [[Monotonic Function]] is simple ([[Monotonic Function One-Sided Limit Theorem]]).
- A [[Derivative]] defined on an interval has no simple discontinuities ([[Darboux's Theorem]]).
- Contrast with [[Discontinuity of the Second Kind]].
