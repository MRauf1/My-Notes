# Definition
> [!info] False Memory[^1]
> Recollection of an event that did not happen, or that happened differently from how it is remembered. Because remembering is reconstructive, each retrieval rebuilds the memory from fragments, current beliefs and suggestion, so memories drift like a message in the telephone game.

# Properties
- **Evidence.**
	- *Misinformation effect.* Misleading post-event information alters eyewitness reports (Loftus and Palmer, 1974).
	- *Implanted memories.* About 25% of adults came to "remember" being lost in a shopping mall as a child after suggestive interviews (Loftus and Pickrell, 1995). A mega-analysis of implantation studies estimated that about 30% of participants form a false memory (Scoboria et al., 2017).
	- Confidence and vividness don't guarantee accuracy, which is why eyewitness testimony is treated with caution.[^1]
- **Coherence.** The mind interprets experience to cohere with prior beliefs and feelings; when past and present clash, it can invent memories to restore coherence.[^2] Compare [[Cognitive Dissonance]].
- **Recovered-memory controversy.** In the 1980s–90s, suggestive therapy produced false memories of childhood abuse. "False memory syndrome" was the (non-diagnostic) label, and lawsuits led recovered-memory techniques to fall out of practice.[^2]
- **Implication.** Since memory and belief are malleable, self-skepticism about one's own certainty is warranted ([[Intellectual Humility]]).[^3]
- Mechanism: [[Reconsolidation]]; see [[Memory]].
