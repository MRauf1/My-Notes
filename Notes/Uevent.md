# Definition
> [!info] Uevent[^1]
> A uevent is a notification event that the [[Kernel (Operating System)|kernel]] sends to [[Udev|udevd]] over an internal netlink connection to announce a device event, carrying a set of attributes that udevd loads and matches against its rules.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=80&annotation=H373V3SN)
