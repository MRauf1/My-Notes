# Definition
> [!definition] Filesystem User ID[^1]
> The filesystem user ID (fsuid) is the [[Process User ID|process user ID]] that defines the user accessing the filesystem.

# Properties
- Rarely used in practice, unlike the [[Effective User ID|effective]], [[Real User ID|real]], and [[Saved User ID|saved]] user IDs.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=188&annotation=5YQX3BKU)
