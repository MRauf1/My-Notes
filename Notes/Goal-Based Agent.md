# Definition
> [!info] Goal-Based Agent[^1]
> An [[Agent Program|agent program]] that combines a model of the world with goal information — a description of desirable situations — to choose actions that achieve the goal.

# Properties
- Goals provide only a crude binary distinction between "happy" and "unhappy" states; a [[Utility-Based Agent|utility-based agent]] generalizes this to a graded comparison between states.

[^1]: [Russell and Norvig, 2022, p. 71](zotero://open-pdf/library/items/JZXT5DZQ?page=71&annotation=MDQZHIC9)
