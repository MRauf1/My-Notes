# Definition
> [!definition] Cron[^1]
> Cron is the Unix service that runs programs repeatedly on a fixed schedule, most often to perform automatic system maintenance.

# Properties
- A program run through cron is called a cron job.[^2]
- Scheduled through [[Crontab|crontab files]].
- One of the oldest components of a Linux system, predating Linux itself; its configuration format has changed little for many years.[^3]
- Proposed replacements are built into modern init implementations instead — timer units for [[Systemd|systemd]], and recurring triggered events for [[Upstart]] — since both can already run tasks as any user and offer advantages such as custom logging.[^4]
