# Definition
> [!info] Dutch Book Theorem (Ramsey, 1926; de Finetti, 1937)[^1]
> If a set of betting prices violates the rules of [[Probabilism|probability]], then there is a Dutch Book consisting of bets at those prices.

A **Dutch Book** is a set of bets, each of which the agent regards as fair at their betting prices, that together guarantee the agent a net loss however the world turns out. An agent's betting price for a proposition $ is the price $ at which they would be willing to either buy or sell a bet paying $ if $ is true and /bin/zsh$ otherwise.

# Properties
- Its converse is the [[Converse Dutch Book Theorem]]; together they say that an agent's betting prices are immune to a Dutch Book if and only if they are probabilities.
- The mathematical core of the [[Dutch Book Argument]] for [[Probabilism]].
