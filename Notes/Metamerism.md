# Definition
> [!info] Definition (Metamerism)[^1]
> The phenomenon in which two physically different light power spectra appear to be the same color to the eye, because they yield the same [[Tristimulus Values|projection]] onto the eye's color-matching functions. Two such spectra are called **metamers**.

# Properties
- Follows from the [[Trichromatic Theory of Color Vision|eye reducing]] the high-dimensional space of light power spectra to a 3D subspace of perceived colors; any two power spectra with the same projection onto that subspace are metamers, so there is a large space of metamers for any given color.
- [[Hyperspectral Imaging]] records many more than three wavelength bands and so can distinguish some metamers that appear identical to the human eye, though in practice it adds only modest additional information for most images.

[^1]: [MIT Vision Book - Color](https://visionbook.mit.edu/color.html)
