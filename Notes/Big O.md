# Definition

> [!info] Definition 1 (Big O)[^1]
> Given two [[Function]] $f, g$, then $f(n)$ is $O(g(n))$ if and only if there exist $c, k \in \mathbb{R}^+$ such that $0 \leq f(n) \leq c g(n)$ for all $n \geq k$.
