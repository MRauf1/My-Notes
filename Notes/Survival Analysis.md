# Definition

[[Regression]] approach for modeling the time until an event of interest occurs (e.g. death, failure, churn), where the output is censored: for some observations the event has not yet occurred by the end of the study, so only a lower bound on their true time is known rather than the exact value.[^1]

[^1]: [Introduction to Statistical Learning with Python](zotero://open-pdf/library/items/9JTAJ2JI?page=22)
