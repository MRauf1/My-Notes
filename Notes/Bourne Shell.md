# Definition
> [!definition] Bourne Shell[^1]
> The Bourne shell (/bin/sh) is a standard [[Shell (Unix)|shell]] developed at Bell Labs for early versions of Unix, from which many other Unix shells derive several of their features.

# Properties
- Every Unix system needs the Bourne shell in order to function correctly.
- [[Bash]] is Linux's enhanced version of the Bourne shell.
- On a Linux system, /bin/sh is normally a link to [[Bash]].
