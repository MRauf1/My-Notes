# Definition
> [!info] Local Version Control System[^1]
> A local version control system is a [[Version Control System]] that keeps the history of a file's changes as patch sets, the differences between successive versions, stored in a special format directly on the local disk; any past version of the file can be reconstructed by cumulatively applying its recorded patches.

# Properties
- RCS is a well-known local version control system that is still distributed with many computers today.
