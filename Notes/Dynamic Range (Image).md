# Definition

> [!info] Definition (Image Dynamic Range)[^1]
> Although possible light intensities are unbounded in principle, any display device has a finite maximum intensity, so pixel values are often restricted to a bounded range, commonly normalized to $[0, 1]$.

# Types
- [[High Dynamic Range Image]]
- [[Low Dynamic Range Image]]

# Properties
- Reducing the number of bits used to store each pixel produces [[Image Artifact|image artifacts]]: [[Clipping]] and [[Quantization Artifact|quantization artifacts (banding)]].
