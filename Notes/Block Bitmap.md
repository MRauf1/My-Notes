# Definition
> [!info] Block Bitmap[^1]
> A block bitmap is a [[Filesystem]] data structure that tracks which blocks in its data pool are free versus in use, reserving one bit per block — 0 for free, 1 for in use — so that allocating or freeing a block is just a matter of flipping a bit.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=115&annotation=Q6UXD8PI)
