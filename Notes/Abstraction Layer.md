# Definition
> [!definition] Abstraction Layer[^1]
> A layer (or level) is a classification of a component in a computing system according to where that component sits between the user and the hardware. Arranging components into layers is what allows abstraction to make a system easier to understand.

# Properties
- A [[Unix|Linux]] system has three main layers, ordered from hardware to user: the hardware, the [[Kernel (Operating System)|kernel]], and [[User Space]].
