# Definition
> [!info] While Loop (Python)[^1]
> Python's most general iteration [[Compound Statement (Python)|compound statement]]: it repeatedly executes its body as long as a test at the top of the loop keeps evaluating to true, and skips the body entirely if the test is false to begin with.

# Properties
- Its full form includes an optional [[Loop Else Clause (Python)|else clause]], run only when the loop exits without hitting a `break`[^2].
- Python has no built-in "do until" loop that always runs its body at least once, but one can be simulated with `while True:` and a `break` guarded by a test at the bottom of the body[^3].
