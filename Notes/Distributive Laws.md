# Definition

> [!info] Definition 1 (Distributive Laws)[^1]
> For [[Proposition|statements]] $P, Q, R$
> $$
> \begin{align}
> P \land (Q \lor R) &\equiv (P \land Q) \lor (P \land R) \\
> P \lor (Q \land R) &\equiv (P \lor Q) \land (P \lor R)
> \end{align}
> $$

# Properties
- A [[Logical Equivalence]]. Unlike arithmetic ([[Distributive Property]]), both connectives distribute over each other.
- Set analogues: $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ and $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$.
