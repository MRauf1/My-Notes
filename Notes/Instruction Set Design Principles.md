# Definition
> [!info] Instruction Set Design Principles[^1]
> A small set of design principles that guide the authors of an [[Instruction Set Architecture]] in balancing simplicity, speed, and cost.

# Types
- [[Simplicity Favors Regularity]] — Design Principle 1.
- [[Smaller Is Faster]] — Design Principle 2.
- [[Good Design Demands Good Compromises]] — Design Principle 3.

# Properties
- Complements [[Make the Common Case Fast]], the analogous design principle from the broader [[Great Ideas in Computer Architecture]].
