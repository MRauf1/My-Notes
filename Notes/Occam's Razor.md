# Definition
> [!info] Definition (Occam's Razor)[^1]
> The principle that, among multiple hypotheses that equally well explain the data, the simplest one should be preferred.

# Properties
- Embodied in machine learning by [[Regularization]], which adds a term to the objective that prefers simpler functions in the [[Hypothesis Space]], all else being equal.
- Given a probabilistic justification by the [[Bayesian Occam's Razor]].

[^1]: [MIT Vision Book - The Problem of Generalization](https://visionbook.mit.edu/problem_of_generalization.html)
