# Definition
> [!info] Relation Maximal Element[^1]
> Let $A$ be a [[Set]] and $\prec$ a [[Strict Partial Order]] on $A$. A maximal element of $A$ is an element $m \in A$ such that there is no $a \in A$ with $m \prec a$.

Equivalently, for a [[Partial Order]] $\leq$: $m \leq a \implies a = m$. The counterpart of the [[Relation Minimal Element]].

# Properties
- A maximal element need not be comparable to every element, so it need not be a largest element, and it need not be unique; in a [[Total Order]] the notions coincide.
- Existence of maximal elements is guaranteed by [[Zorn's Lemma]] when every chain has a [[Relation Upper Bound|upper bound]].
