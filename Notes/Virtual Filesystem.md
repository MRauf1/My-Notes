# Definition
> [!info] Virtual Filesystem[^1]
> A [[Filesystem]], mountable alongside on-disk filesystems on POSIX systems such as Linux and macOS, whose files are generated dynamically or stored in RAM rather than read from a persistent storage medium.

# Properties
- Linux provides three main virtual filesystems.
