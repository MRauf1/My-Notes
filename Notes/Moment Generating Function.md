# Definition

> [!info] Definition 1 (Moment Generating [[Function]])[^1]
> Let $X$ be [[Random Variable]] such that for some $h > 0$, the [[Expectation]] of $e^{tX}$ exists for $-h < t < h$. Then the mgf of $X$ is defined to be $M_X(t) = E[e^{tX}]$ for $-h < t < h$.
> It is enough for the neighborhood to be about 0.

The integrals/sums are called the moments. $E[X^m]$ is called the $m$th moment of $X$.

Not all [[Probability Distribution]] have mgf.

# Types
- [[Expectation]] is $M'(0)$
- $M^{(m)}(0) = E[X^m]$
