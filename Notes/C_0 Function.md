# Definition

> [!info] Definition 1 ($C^0$ [[Function]])[^1]
> [[Real-Valued Function]] $f: U \rightarrow \mathbb{R}$ is $C^0$ at $p$ if it is [[Continuous Function]] at $p$.
> Similar definition holds for when $f$ is [[Real Vector-Valued Function]] with the only addition being that the component [[Function]] $f^1, \dots, f^m$ are individually $C^{0}$.

[^1]: [Introduction to Manifolds](zotero://open-pdf/library/items/4Y95WRJU?page=23)
