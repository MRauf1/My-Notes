# Definition

> [!info] Definition (Raster Image)[^1]
> A raster image is a 2D array storing a pixel value—usually a color as three numbers for red, green, and blue—for each pixel. It can be displayed by using each stored pixel to control the color of the corresponding pixel of a display.

# Properties
- It is best understood as a device-independent description of the image to be displayed, with the display device approximating that ideal image.
- Each pixel of a raster image is a [[Point Sample]] of the underlying [[Digital Image]].
- Indexing and domain conventions for a raster image are given by [[Raster Image Coordinate Convention]].
- Contrasts with [[Vector Image]], which stores shape instructions rather than sampled pixels.
- A type of [[Digital Image]].

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=68&annotation=6QKT4SFD)
