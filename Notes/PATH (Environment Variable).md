# Definition
> [!definition] PATH (Environment Variable)[^1]
> PATH is a special [[Environment Variable]] that contains the command path: a list of system directories that the [[Shell (Unix)|shell]] searches when trying to locate a command.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=47&annotation=JDYA3GNV)
