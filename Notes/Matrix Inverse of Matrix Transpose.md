# Definition

> [!abstract] Theorem 1 ([[Matrix Inverse]] of [[Matrix Transpose]])[^1]
> If $A$ is [[Invertible Linear Map]], then $A^T$ is also [[Invertible Linear Map]] and $(A^T)^{-1} = (A^{-1})^T$.
> The same holds true for [[Matrix Conjugate Transpose]] with $*$ replacing $T$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=121)
