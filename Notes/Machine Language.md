# Definition
> [!info] Machine Language[^1]
> A binary representation of machine [[Instruction|instructions]], produced from [[Assembly Language]] by an [[Assembler]].

# Properties
- The only language computer hardware directly executes; every higher-level abstraction ultimately compiles or assembles down to it.
- Governed by a computer's [[Instruction Set Architecture]].

[^1]: [Computer Organization and Design: The Hardware/Software Interface](zotero://open-pdf/library/items/YWPB5EDC?page=37&annotation=TLT6TTZU)
