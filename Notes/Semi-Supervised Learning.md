# Definition

[[Statistical Learning]] task in which some observations have labels and some don't. As such, it's a mixture of both [[Supervised Learning]] and [[Unsupervised Learning]].[^1]

# Properties
- [[Transductive Learning]], which labels the given unlabelled examples using patterns in both the labelled and unlabelled data, is sometimes termed semi-supervised learning; node classification on a single partially labelled graph with a [[Graph Neural Network]] is a typical instance.[^2]
