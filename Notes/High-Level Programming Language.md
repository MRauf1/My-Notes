# Definition
> [!info] High-Level Programming Language[^1]
> A portable language, such as C, C++, Java, or Visual Basic, composed of words and algebraic notation that a [[Compiler]] can translate into [[Assembly Language]].

# Properties
- Lets programmers think in a more natural language suited to the problem domain, and lets languages be designed according to their intended use.
- Improves programmer productivity: programs are shorter and easier to write than the equivalent [[Assembly Language]].
- Makes programs independent of the computer on which they were developed, since a [[Compiler]] and [[Assembler]] can translate a high-level language program into the binary instructions of any target computer.
