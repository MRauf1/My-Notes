# Definition
> [!info] Docstring (Python)[^1]
> Documentation automatically attached to an [[Object (Python)|object]] and retained at runtime: a [[Python String|string]] literal placed at the very top of a module file, or of a function or class statement, before any other executable code.

# Properties
- Its text is automatically stored in the corresponding object's `__doc__` attribute, making it available for inspection at runtime rather than discarded like an ordinary `#` comment[^1].
