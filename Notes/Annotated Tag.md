# Definition
> [!info] Annotated Tag[^1]
> An annotated tag is a [[Git Tag]] stored as a full, checksummed object in the Git database, containing the tagger's name, email, and date, a tagging message, and optionally a cryptographic signature that others can verify.

# Properties
- Because they carry this additional, checksummed information, annotated tags are generally the recommended tag type, while [[Lightweight Tag|lightweight tags]] remain useful for quick or temporary markers that don't need it.
