# Definition
> [!info] First-Class Function (Python)[^1]
> Like every other value in Python, a [[Function (Python)|function]] is itself an [[Object (Python)|object]]: it can be assigned to another name, stored in a data structure, passed as an argument, or returned from another function, and may have arbitrary user-defined attributes attached to it.

# Properties
- This first-class treatment of functions is what makes higher-order, functional-style programming possible in Python: functions can be processed generically by other code, just like numbers or strings.
