# Definition
> [!info] Definition 1 (Non-Decreasing [[Function]])[^1]
> For a [[Function|function]] $f$ on an [[Interval Notation|interval]] $I$, $f$ is non-decreasing on $I$ $\iff$ $f(a) \le f(b)$ for all [[Real Number|real numbers]] $a, b$ in $I$ with $a < b$.

# Properties
- Unlike an [[Increasing Function|(strictly) increasing function]], a non-decreasing function may stay constant as well as rise as the input increases; equal outputs $f(a) = f(b)$ for $a < b$ are permitted.
- [[Inequality Sign Change]]: applying a non-decreasing function to a strict [[Inequality]] ($a < b$) only guarantees the weak conclusion $f(a) \le f(b)$, not the strict conclusion $f(a) < f(b)$.
