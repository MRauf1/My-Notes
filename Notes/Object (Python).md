# Definition
> [!info] Object (Python)[^1]
> A piece of memory with an associated value and a set of supported operations. Every piece of data in a Python script — from a simple number to a class instance — is an object.

# Properties
- Python programs are built from four concrete layers: modules, statements, expressions, and objects, with objects sitting at the bottom of that hierarchy[^2].
- Besides the built-in core object types such as strings, numbers, lists, and dictionaries, program units like functions, modules, and classes are objects too — created with statements such as `def`, `class`, `import`, and `lambda` — and can be passed around, stored, and manipulated like any other object[^3].
- Core object types are distinguished only by having dedicated literal/expression syntax built into the language itself; conceptually, everything a Python program processes is some kind of object[^4].
- Every object is classified as either [[Mutability (Python)|mutable or immutable]], and every variable that refers to one is [[Dynamic Typing (Python)|dynamically]] and [[Strong Typing (Python)|strongly]] typed through the object rather than the variable name.
