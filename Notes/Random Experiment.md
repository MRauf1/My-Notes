# Definition
> [!info] Random Experiment[^1][^2]
> An experiment such that
> 1. it can be repeated under essentially the same conditions,
> 2. its outcome cannot be predicted with certainty before it is performed,
> 3. the collection of every possible outcome can be described before it is performed.
>
> That collection of outcomes is the [[Sample Space]] $\mathcal{C}$.

Although a single outcome is unpredictable, over many repetitions the [[Relative Frequency]] of an [[Event]] stabilizes, and this stable value is what [[Probability]] models.

# Properties
- Repetitions whose events are [[Mutually Independent Events|independent]] of each other are called independent experiments.
- A [[Random Variable]] assigns a number to each outcome of a random experiment.
