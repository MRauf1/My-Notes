# Definition
> [!info] Strong Typing (Python)[^1]
> A typing constraint, used by Python, meaning that a script can perform on an [[Object (Python)|object]] only the operations that are valid for that object's type.

# Properties
- Complements [[Dynamic Typing (Python)|dynamic typing]]: Python infers an object's type automatically, but still enforces that only type-appropriate operations run on it — e.g., adding a string of digits to an integer is an error unless one operand is manually converted.
