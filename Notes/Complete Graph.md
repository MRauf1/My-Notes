# Definition

> [!info] Definition 1 (Complete [[Graph]])[^1]
> [[Graph]] in which every [[Vertex]] is connected to every other [[Vertex]].
> It is denoted as $K_n$ where $n$ is the number of [[Vertex]].

![[Pasted image 20260602185257.png]]

# Properties
- $|E| = \sum_{k=0}^{n - 1} k = \frac{n(n - 1)}{2}$
