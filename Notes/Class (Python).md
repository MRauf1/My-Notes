# Definition
> [!info] Class (Python)[^1]
> A Python program unit, alongside [[Function (Python)|functions]] and [[Module (Python)|modules]], that packages logic and data and defines a new namespace; unlike the others, a class is also a factory for generating [[Instance (Python)|instances]], supports customization via inheritance in subclasses, and can intercept built-in-type operations through operator overloading.

# Properties
- Created by an executable `class` [[Compound Statement (Python)|statement]], which, when reached and run, generates a new class object and assigns it to the name in its header, typically the first time the enclosing module is imported[^2].
- An assignment made at the top level of the class body — most commonly a nested `def` — attaches a class attribute, shared by every instance and subclass generated from it[^2].
- Calling a class like a function creates and returns a new instance object[^3].
