# Definition
> [!info] Linear Programming (Markov Decision Process)
> An approach to [[Planning]] that casts the problem of computing $\pi^\star$ as a linear program (LP), solvable with general-purpose LP solvers.

# Types
- [[Primal Linear Program (Markov Decision Process)]]
- [[Dual Linear Program (Markov Decision Process)]]

# Properties
- An alternative to [[Policy Iteration]] and [[Value Iteration]] for [[Planning]].
