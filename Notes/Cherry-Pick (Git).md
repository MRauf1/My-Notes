# Definition
> [!info] Cherry-Pick[^1]
> A cherry-pick is an operation that takes the patch introduced by a single commit and reapplies it on the branch currently checked out, functioning like a [[Rebasing (Git)|rebase]] restricted to just that one commit.

# Properties
- This is useful for integrating just one, or a few, specific commits out of a [[Topic Branch]], rather than that branch's entire history.
