# Definition

> [!info] Definition 1 (Linearly Independent)[^1]
> List of [[Vector]] $(v_1, \dots, v_n)$ in $V$ is linearly independent if they are not [[Linearly Dependent]].
> In other words, they are linearly independent if and only if the only choice of scalars $a_1, \dots, a_n \in \mathbb{F}$ for which $\sum_{j=1}^n a_j v_j = 0$ is $a_1 = \dots = a_n = 0$.

A list of [[Vector]] with no redundancy.
