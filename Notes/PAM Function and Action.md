# Definition
> [!definition] PAM Function and Action[^1]
> A PAM function is the high-level goal a user application wants [[Pluggable Authentication Modules (PAM)|PAM]] to accomplish, such as authenticating a user, while a PAM action is one specific step PAM takes toward that goal.

# Properties
- The user application invokes the function first, and PAM then carries out the particulars through one or more actions.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=194&annotation=JM2EWBBC)
