# Definition
> [!info] Pull Request[^1]
> A pull request is a request sent to the maintainer of a canonical repository asking them to merge in changes a contributor has pushed to their own public fork of the project, as part of an [[Integration-Manager Workflow]].

# Properties
- A pull request is often treated less as a finished, ready-to-apply patch and more as the start of an iterative conversation about a proposed change, which culminates in a single unified diff being merged once the change is agreed upon.
