# Definition

> [!info] Definition 1 ([[Matrix]] [[Inverse]])[^1]
> Let $A \in M_n(\mathbb{F})$. The [[Matrix]] $B \in M_n(\mathbb{F})$ is an inverse of $A$ if $AB = BA = I_n$.
> If $A$ has an inverse, then we say that $A$ is an [[Invertible Linear Map]] or [[Nonsingular Matrix]]. If it doesn't have an inverse, then we say that $A$ is [[Singular Matrix]].
> The inverse matrix is unique and denoted by $A^{-1}$.
> Non-square matrices can never be invertible.
