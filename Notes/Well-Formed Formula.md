# Definition

> [!info] Definition 1 (Well-Formed Formula)[^1]
> A well-formed formula (or just formula) is an expression built grammatically from statement letters using the connectives [[Not|¬]], [[And|∧]], [[Or|∨]] (and later →, ↔) and parentheses: every letter is a formula, and if $P, Q$ are formulas then so are $\neg P$, $(P \land Q)$, $(P \lor Q)$.

# Properties
- Strings such as $\neg(P, Q, \land R)$ or $(P \land Q)(P \lor R)$ are not formulas, since no rule produces them.
- Only formulas have truth values and [[Truth Table|truth tables]].
