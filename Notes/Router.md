# Definition
> [!definition] Router[^1]
> A router is a [[Host (Networking)|host]] attached to more than one network that can move data from one network to another; also called a gateway.

# Properties
- A [[Computer Network (LAN and WAN)|LAN]]'s router, connected to both the LAN and the Internet, gives every machine on the LAN Internet access through it.[^2]
- Serves as a network's [[Default Gateway|default gateway]], and may additionally share a single public [[IP Address]] among a private network's hosts via [[Network Address Translation (NAT)|NAT]].
