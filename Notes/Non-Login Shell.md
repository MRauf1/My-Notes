# Definition
> [!definition] Non-Login Shell[^1]
> A non-login shell is any interactive [[Shell (Unix)|shell]] that is not a [[Login Shell|login shell]] — an additional shell run after the user has already logged in.

# Properties
- Windowing-system terminal programs, such as xterm or GNOME Terminal, start non-login shells unless a login shell is specifically requested.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=317&annotation=L47TYRAZ)
