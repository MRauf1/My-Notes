# Definition

> [!info] Definition 1 (Imaginary Unit)[^1]
> The imaginary unit, denoted as $i$, is $\sqrt{-1}$ that satisfies the following definitional properties
> 1) $i^2 = -1$
> 2) $c \in \mathbb{R}, c \geq 0 \implies \sqrt{-c} = i \sqrt{c}$

# Properties
- Its powers cycle with period 4: $i^1 = i$, $i^2 = -1$, $i^3 = -i$, $i^4 = 1$, so $i^n$ depends only on $n \bmod 4$.[^sigworth]
- $|i| = 1$ ([[Absolute Value of Complex Number]]); in polar form $i = e^{i\pi/2}$ ([[Euler's Identity]]).
