# Definition

> [!info] Definition (High Dynamic Range (HDR) Image)[^1]
> A high dynamic range (HDR) image stores pixel values with floating-point numbers, allowing a wide range of intensity values rather than a fixed bounded range.

# Properties
- Contrasted with [[Low Dynamic Range Image|low dynamic range (LDR) images]], which are stored with integers over a fixed range.
- A type of [[Dynamic Range (Image)|image dynamic range]].

[^1]: [Fundamentals of Computer Graphics](zotero://open-pdf/library/items/7B6A4MRC?page=68&annotation=6QKT4SFD)
