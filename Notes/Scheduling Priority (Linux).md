# Definition
> [!definition] Scheduling Priority (Linux)[^1]
> A process's scheduling priority is the number, ranging from –20 (foremost) to 20, by which the Linux kernel's [[CPU Scheduling|scheduler]] decides how much CPU time to give the process relative to others.

# Properties
- Influenced indirectly through the process's [[Nice Value|nice value]] rather than set directly.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=204&annotation=MR5IJ7BB)
