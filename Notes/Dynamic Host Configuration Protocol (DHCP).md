# Definition
> [!definition] Dynamic Host Configuration Protocol (DHCP)[^1]
> DHCP is the protocol that lets a host automatically obtain its [[IP Address|IP address]], subnet mask, [[Default Gateway|default gateway]], and [[Domain Name System (DNS)|DNS]] servers from the network, rather than requiring manual configuration.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=239&annotation=9TNAKCFV)
