# Definition
> [!info] Gitignore[^1]
> A gitignore file lists patterns matching files that [[Git]] should not automatically track or report as untracked, such as automatically generated log files or files produced by a build system.

# Properties
- Files matching a listed pattern remain excluded from [[Git File States|tracking and untracked-file reporting]] even though they still exist in the working tree.
