# Definition
> [!definition] Window Manager[^1]
> A window manager is the [[X Window System|X client]] responsible for arranging windows on screen and providing interactive decorations, such as title bars, that let a user move and minimize them.

# Properties
- Perhaps the most important client service application in a desktop, since these elements are central to the user experience.[^1]
- Started by a [[Display Manager|display manager]] along with other clients once a user logs in.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=323&annotation=WTYFZBEA)
