# Definition
> [!definition] Graphical Toolkit[^1]
> A graphical toolkit is a library that provides an application's common interface elements, called widgets, such as buttons and menus, to speed up development and give applications a common look.

# Properties
- Usually consists of shared libraries and support files, such as images and theme information.[^2]
- Provides only a uniform outward appearance; cooperation between different applications, such as sharing data or updating a shared notification bar, requires further bundling into a [[Desktop Environment]].[^3]
- At the core of most desktop environments.[^4]
