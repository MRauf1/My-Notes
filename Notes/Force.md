# Definition

Push or pull in a particular direction that is represented using [[Vector]].[^1]

It is calculated by [[Newton's Second Law]] and is measured in N (Newtons).

# Properties
- All known forces between particles arise from the [[Four Fundamental Interactions]]: the strong, electromagnetic, weak, and gravitational interactions.
