# Definition

Let $-C$ be the same path but opposite orientation as $C$.
- $\int_{-C} f(x, y) dx = - \int_C f(x, y) dx$
- $\int_{-C} f(x, y) dy = - \int_C f(x, y) dy$
- $\int_{-C} f(x, y) ds = \int_C f(x, y) ds$
