# Definition

> [!abstract] Theorem 1 ([[Basis]] [[Linear Combination]])[^1]
> A list of [[Vector]] $\mathcal{B} = (v_1, \dots, v_n)$ is a [[Basis]] of $V$ if and only if each element of $V$ can be uniquely represented as a [[Linear Combination]] of the [[Vector]] in $\mathcal{B}$.
