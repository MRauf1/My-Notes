# Definition

> [!abstract] Theorem 1 ([[Basis]] [[Matrix]] [[Reduced Row Echelon Form]])[^1]
> List $(v_1, \dots, v_n)$ of [[Vector]] in $\mathbb{F}^m$ forms a [[Basis]] for $\mathbb{F}^m$ if and only if the [[Reduced Row Echelon Form]] of this [[Matrix]] (with $v_i$ being the columns) is $I_m$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=172)
