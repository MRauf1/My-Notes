# Definition
> [!info] Venn Diagram[^1]
> A diagram representing the [[Sample Space]] $\mathcal{C}$ as a rectangle and [[Event|events]] as regions inside it, so that [[Set Operations]] become operations on regions: the [[Set Complement|complement]] $A^c$ is the area outside $A$, the [[Set Union|union]] $A \cup B$ is the area covered by either region, and the [[Set Intersection|intersection]] $A \cap B$ is the overlap.

# Properties
- Useful for seeing identities such as the [[Distributive Property|distributive laws]] and [[DeMorgan's Laws]], and for decomposing a set into [[Disjoint Set Union|disjoint unions]], e.g. $A \cup B = A \cup (A^c \cap B)$ and $B = (A \cap B) \cup (A^c \cap B)$, which give the [[Probability of Set Union]].
- A picture, not a proof: it illustrates at most a few sets in general position.
