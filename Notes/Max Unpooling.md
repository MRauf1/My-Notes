# Definition
> [!info] Max Unpooling[^1]
> An [[Upsampling (Deep Learning)|upsampling]] operation, used where a [[Max Pooling]] operation was previously used for downsampling, that distributes each value to the position its maximum originated from (filling the other positions of the block with zeros).

# Properties
- Requires storing the argmax locations from the corresponding max pooling layer.
