# Definition
> [!definition] Web Server[^1]
> A web server is a program that, by itself, does little more than serve files; its real purpose is to act as an underlying platform for serving web applications.

# Properties
- Web applications built on it are highly modular, so it is easy to extend them or build new ones with a [[Web Application Framework|web application framework]].[^2]
- Depends on a solid operating system foundation: flawless network configuration, and adequately sized, efficient memory and disk, especially when the application uses a [[Database (Computing)|database]].[^3]
