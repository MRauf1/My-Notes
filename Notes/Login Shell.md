# Definition
> [!definition] Login Shell[^1]
> A login shell is the initial [[Shell (Unix)|shell]] a user gets when first logging in to a system, traditionally via a terminal program such as `/bin/login`, or remotely over SSH.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=317&annotation=ILKRTVDV)
