# Definition

> [!info] Definition 1 (Complete [[Bipartite Graph]])[^1]
> [[Graph]] that is [[Bipartite Graph]] with $m$ [[Vertex]] in $V_1$ and $n$ [[Vertex]] in $V_2$ that contains all possible [[Edge]] that are consistent with the definition of a [[Bipartite Graph]].
> It is denoted as $K_{m, n}$ with $m + n$ [[Vertex]].

# Properties
- $|E| = mn$
