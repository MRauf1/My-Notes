# Definition
> [!info] Git Attributes[^1]
> Git attributes are path-specific settings that let [[Git]] apply certain behaviors only to a particular subdirectory or subset of files, rather than to the whole repository.

# Properties
- Attributes set in a `.gitattributes` file inside the project are versioned and shared along with the repository, whereas attributes set in `.git/info/attributes` remain purely local and are never committed with the project.

[^1]: [Pro Git](zotero://open-pdf/library/items/Y53JUJJW?page=352&annotation=ZGJ7FIEZ)
