# Definition
> [!info] Event[^1][^2]
> An event is a [[Subset]] $A \subseteq \mathcal{C}$ of the [[Sample Space]] (the [[Universe of Discourse|outcome space]]) of a [[Random Experiment]], belonging to the [[Sigma-Field]] $\mathcal{B}$ of events. If the experiment results in an outcome $c \in A$, the event $A$ is said to have occurred.

Events are usually denoted by capital letters $A, B, C$ and outcomes by lowercase letters $a, b, c$.

# Types
- [[Mutually Exclusive Events]]
- [[Exhaustive Events]]
- [[Independent Events]]

# Properties
- Events combine through [[Set Operations]] ([[Set Complement|complement]], [[Set Union|union]], [[Set Intersection|intersection]]), visualized with a [[Venn Diagram]].
- [[Probability]] is a set function on events.
