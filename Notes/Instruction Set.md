# Definition
> [!info] Instruction Set[^1]
> The vocabulary of commands understood by a given architecture.

# Properties
- Narrower than the [[Instruction Set Architecture]], which additionally specifies registers, memory access, and I/O behavior needed to write a correct [[Machine Language]] program.
- Its design is guided by the [[Instruction Set Design Principles]].
- Every computer's instruction set must be able to perform arithmetic, move data between [[Register (Computer Architecture)|registers]] and [[Main Memory]] ([[Data Transfer Instruction|data transfer instructions]]), make decisions ([[Conditional Branch|conditional branches]]), and manipulate bits (logical operations).

[^1]: [Computer Organization and Design: The Hardware/Software Interface](zotero://open-pdf/library/items/YWPB5EDC?page=85&annotation=FLNZJ9RY)
