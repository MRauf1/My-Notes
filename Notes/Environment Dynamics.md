# Definition
> [!info] Static vs. Dynamic Environment[^1]
> A dimension of a [[Task Environment|task environment]]: it is dynamic for an agent if the environment can change while the agent is deliberating, and static otherwise.

# Types
- Static - the environment does not change while the agent decides on an action.
- Dynamic - the environment continuously changes while the agent deliberates; failing to decide counts as deciding to do nothing.
- Semidynamic - the environment itself does not change with the passage of time, but the agent's performance score does.

# Properties
- Static environments are easy to deal with, since the agent need not keep watching the world while deciding, nor worry about the passage of time.
