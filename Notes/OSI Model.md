# Definition
> [!info] OSI Model[^1]
> The Open Systems Interconnection (OSI) model: a seven-layer model defining standards for both the infrastructure and the protocols used for network communication, such as the Internet.

# Types
- Physical layer
- Data link layer
- Network layer — implemented by protocols such as the [[Internet Protocol]].
- Transport layer — implemented by protocols such as [[Transmission Control Protocol (TCP)|TCP]] and [[User Datagram Protocol (UDP)|UDP]].
- Session layer
- Presentation layer
- [[Application Layer]] (layer 7)

[^1]: [Systems Programming](zotero://open-pdf/library/items/8Y3AE875?page=245&annotation=4A38FY4F)
