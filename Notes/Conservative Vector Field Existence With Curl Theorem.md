# Definition

> [!abstract] Theorem 1 ([[Conservative Vector Field]] with [[Curl of Vector Field]])[^1]
> If $F$ is a [[Vector Field]] defined everywhere on $\mathbb{R}^3$ and whose component [[Function]] have [[Continuous Function]] [[Partial Derivative]] and [[Curl of Vector Field]] $F$ is 0, then $F$ is a [[Conservative Vector Field]].

[^1]: [Calculus: Early Transcendentals](zotero://open-pdf/library/items/EEFDQ9Y5?page=1137)
