# Definition
> [!info] Parkinson's Law[^1]
> "Work expands so as to fill the time available for its completion" (Parkinson, 1957), like air filling every corner of a room.

# Properties
- It holds almost universally for longer time frames, but the *opposite* is true for tasks that can be finished in one go. Partly because of the [[Zeigarnik Effect]], the brain stays occupied with a task until it is done or written down, which pushes toward completion.[^1]
- Implication: break work into small, self-contained tasks with clear endpoints (cf. [[Planning Fallacy]]).
