# Definition

> [!info] Definition 1 ([[Graph]] Coloring)[^1]
> A coloring of [[Graph]] $G$ assigns a color to each [[Vertex]] of $G$ such that no two [[Adjacent Vertices]] have the same color.
> If $G$ can be colored with $k$ colors, then it is $k$-colorable.
