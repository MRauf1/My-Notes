# Definition
> [!info] Lottery Paradox (Kyburg, 1961)[^1]
> Given a lottery with $100$ tickets where exactly $1$ will win, the [[Threshold Theory of Acceptance]] (with threshold $t = 0.95$) implies an agent should accept, for each ticket, that it will lose, since each has credence $0.99 > t$. By [[Acceptance Closure]], the agent should then accept the conjunction that all tickets will lose. But the agent also knows exactly one ticket will win, so should accept the negation of this conjunction, and by [[Acceptance Closure]] again, should accept a contradiction.

# Properties
- Arises from the mismatch between probabilistic [[Credence|credence]] and [[Acceptance Closure]]: whenever two hypotheses each individually have credence just above $t$ while their conjunction has credence just below $t$, the [[Threshold Theory of Acceptance]] and [[Acceptance Closure]] give conflicting verdicts.
- Persists for any threshold $t < 1$, since a large enough lottery can always be constructed to reproduce the mismatch.
- Motivates the [[Certainty Theory of Acceptance]], the version of the [[Threshold Theory of Acceptance]] with $t = 1$.

[^1]: [A Critical Introduction to Formal Epistemology](zotero://open-pdf/library/items/9XYCZDPF?page=28)
