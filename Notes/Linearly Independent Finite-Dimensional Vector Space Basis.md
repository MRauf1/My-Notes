# Definition

> [!abstract] Theorem 1 ([[Linearly Independent]] [[Finite-Dimensional Vector Space]] [[Basis]])[^1]
> Suppose that $V$ is [[Finite-Dimensional Vector Space]] and $\mathcal{B}$ is a [[Linearly Independent]] list of [[Vector]] in $V$. Then $\mathcal{B}$ can be extended to a [[Basis]] of $V$. That is, there is a [[Basis]] for $V$ which contains $\mathcal{B}$.

[^1]: [Linear Algebra (Cambridge Mathematical Textbooks) -- Elizabeth S_ Meckes, Mark W_ Meckes](zotero://open-pdf/library/items/HG5B3R7J?page=187)
