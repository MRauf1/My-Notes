# Definition
> [!info] Simplicity Favors Regularity (Design Principle 1)[^1]
> A regular, rigid instruction format simplifies hardware design. For example, each MIPS arithmetic [[Instruction]] performs only one operation and always has exactly three operands, rather than a variable number.

# Properties
- One of the [[Instruction Set Design Principles]].
- Reflected in the uniform three-operand form of MIPS arithmetic instructions and in keeping [[Instruction Format|instruction formats]] similar to each other despite their different fields.

[^1]: [Computer Organization and Design: The Hardware/Software Interface](zotero://open-pdf/library/items/YWPB5EDC?page=88&annotation=W9E25Q55)
