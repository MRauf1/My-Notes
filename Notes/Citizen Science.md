# Definition
> [!info] Citizen Science[^1]
> Scientific research in which members of the public contribute to data collection or analysis, e.g. classifying galaxy images in the online Galaxy Zoo game or capturing local observations with mobile phone cameras.

# Properties
- Quality control via redundancy: the same item is served to multiple users as a reference benchmark to measure each participant's accuracy.[^1]
- Visualisation and analysis challenges are more common across fields than different; progress depends on linking citizen scientists, accessible image browsers, and tools mashed up from common components.[^2]
- The public can augment limited satellite and sensor networks in [[Applications Science]].[^3]
- A resource for [[Data-Intensive Science]].
