# Definition

Percent is a [[Ratio|ratio]] with a denominator of 100. It is denoted using the percent symbol $\%$.[^1]

# Properties
- $a\%$ of $b$ equals $b\%$ of $a$, since both equal $\frac{ab}{100}$.
