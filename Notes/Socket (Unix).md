# Definition
> [!definition] Socket (Unix)[^1]
> A socket is the interface a Unix process uses to identify when and how it is talking to the network, forming the boundary between user space and kernel space.

# Properties
- Often also used for [[Inter-Process Communication]] rather than genuine networking.[^1]
- A [[Unix Domain Socket|Unix domain socket]] is a variant used for IPC on the same machine, with no actual network behind it.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=271&annotation=3NEYWHRS)
