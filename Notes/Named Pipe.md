# Definition
> [!info] Named Pipe[^1]
> A named pipe is a [[Device File]] that behaves like a [[Character Device]], except that the other end of its I/O stream is another process rather than a kernel driver.

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=72&annotation=GK2DH76P)
