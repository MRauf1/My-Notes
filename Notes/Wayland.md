# Definition
> [!definition] Wayland[^1]
> Wayland is a newer display-server standard, built around a [[Compositing Window Manager|compositing window manager]], whose most significant piece is a protocol defining how clients talk to that compositing window manager.

# Properties
- Also includes input device management and a compatibility system for the older [[X Window System]].[^1]
- Maintains, as a protocol, the idea of network transparency.[^1]
- Supported by many pieces of the Linux desktop.[^1]

[^1]: [How Linux Works: What Every Superuser Should Know](zotero://open-pdf/library/items/B4TILA8A?page=330&annotation=G9KP5R9Y)
