# Definition
> [!info] Git Hook[^1]
> A Git hook is a custom script that [[Git]] fires off automatically when a particular action occurs, letting a user extend or enforce behavior around that action.

# Properties
- Client-side hooks run in response to local operations such as committing or merging.
- Server-side hooks run in response to network operations such as receiving pushed commits.
