# Definition
> [!info] Utility Function[^1]
> A function, internal to an agent, that assigns a numerical measure of desirability ("happiness") to a state or sequence of states; it is essentially an internalization of the agent's [[Performance Measure|performance measure]].

# Properties
- A [[Utility-Based Agent|rational utility-based agent]] chooses the action that maximizes the [[Expected Utility|expected utility]] of its outcomes.
- Any rational agent must behave as if it possesses a utility function whose expected value it tries to maximize, turning the "global" definition of rationality into a "local" constraint on agent design.

[^1]: [Russell and Norvig, 2022, p. 72](zotero://open-pdf/library/items/JZXT5DZQ?page=72&annotation=GKX83AFW)
