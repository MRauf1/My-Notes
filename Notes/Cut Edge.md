# Definition

> [!info] Definition 1 (Cut [[Edge]])[^1]
> If two parts of a [[Graph]] are connected by a single [[Edge]], so that the [[Graph]] would be disconnected if this [[Edge]] was removed, then this [[Edge]] is a cut edge.

[^1]: [Building Blocks for Theoretical Computer Science](zotero://open-pdf/library/items/5IGT8C55?page=124)
